# 악마의 주사위: 계약의 눈금
## DEVIL'S DICE — Steam 출시 목표 게임 기획서 v1.0

> **한 줄 소개:** 주사위를 굴리는 게임이 아니라, 주사위가 작동하는 법칙을 바꾸는 게임.  
> **핵심 키워드:** 2D 인디 로그라이크 · 턴제 전투 · 주사위 조합 · 규칙 변형 · 시너지 · 연쇄 발동

---

## 1. 게임 개요

### 1.1 기본 콘셉트

플레이어는 악마와 계약한 도박사다. 영혼을 담보로 악마의 주사위를 얻고, 지하 세계의 여러 구역을 돌파해야 한다.

각 구역의 적을 물리치고 계약과 유물을 획득하면서 주사위의 규칙을 바꾼다. 마지막에는 자신이 만든 조합과 시너지 엔진으로 악마에게 도전한다.

이 게임은 단순히 높은 숫자를 뽑는 주사위 게임이 아니다. **주사위 조합을 만들고, 조합의 발동 규칙을 바꾸고, 여러 효과가 서로 연결되는 구조를 설계하는 게임**이다.

### 1.2 기본 사양

| 항목 | 방향 |
|---|---|
| 장르 | 턴제 전투 로그라이크 |
| 플랫폼 | PC / Steam |
| 그래픽 | 2D 핸드드로잉 일러스트 |
| 화면 구성 | 고정 화면, 전투 중심 |
| 플레이 방식 | 싱글 플레이 |
| 조작 | 마우스 중심 |
| 목표 플레이 시간 | 1회 약 20~35분 |
| 핵심 재미 | 독특한 조합 발견, 시너지 구성, 연쇄 발동 |
| 개발 방향 | 중소규모 인디 게임 |

### 1.3 핵심 재미

1. 주사위를 굴릴 때마다 어떤 조합을 만들 수 있을지 기대한다.
2. 유물과 계약을 얻을수록 기존에는 불가능했던 조합이 가능해진다.
3. 후반에는 작은 조합 하나가 연쇄적으로 발동해 큰 효과를 만든다.
4. 매 원정마다 다른 계약과 유물 조합으로 새로운 빌드를 실험한다.

## 2. 핵심 게임 루프

한 번의 원정은 다음 흐름으로 진행한다.

1. **경로 선택:** 일반 전투, 정예 전투, 상점, 이벤트, 휴식, 보스 중 다음 장소를 선택한다.
2. **주사위 전투:** 주사위를 굴리고, 일부를 다시 굴리고, 최종 결과를 배치해 조합을 만든다.
3. **효과 처리:** 주사위 기본 효과와 조합 효과, 유물·계약 시너지를 순서대로 발동한다.
4. **보상 획득:** 주사위, 유물, 계약, 체력 회복 등 보상 중 하나를 선택한다.
5. **빌드 강화:** 기존 조합을 강화하거나 새로운 조합 규칙을 추가한다.
6. **보스 도전:** 해당 구역에서 만든 시너지 엔진을 활용해 보스를 쓰러뜨린다.
7. **원정 종료 및 해금:** 성공 또는 실패에 따라 기록과 해금 요소를 획득한다.

### 원정에서 전달해야 할 감정

- **초반:** 어떤 조합을 만들지 탐색하는 재미
- **중반:** 조합이 맞아떨어지기 시작하는 재미
- **후반:** 연쇄 발동으로 강력한 효과를 만드는 재미

성장에 따라 단순히 공격력이 증가하는 것보다, 게임의 작동 방식 자체가 달라지는 경험을 우선한다.

## 3. 전투 시스템

### 3.1 기본 전투 구성

초기 전투는 주사위 5개를 중심으로 설계한다.

| 요소 | 초기 규칙 |
|---|---|
| 주사위 | 5개 |
| 주사위 면 | 각 6면 |
| 최초 굴림 | 1회 |
| 재굴림 | 원하는 주사위만 선택해 1회 |
| 배치 | 최종 결과 5개의 순서를 자유롭게 변경 |
| 전투 | 턴제 |
| 적 행동 | 플레이어 턴 전에 행동을 예고 |

### 3.2 전투 진행 순서

1. 주사위 5개를 굴린다.
2. 다시 굴릴 주사위를 선택한다.
3. 선택한 주사위를 재굴림한다.
4. 최종 결과를 5개 슬롯에 배치한다.
5. 왼쪽부터 오른쪽으로 주사위 효과를 처리한다.
6. 조합 조건이 충족되면 조합 효과를 발동한다.
7. 유물과 계약의 반응 효과를 처리한다.
8. 적의 행동을 처리하고 다음 턴으로 넘어간다.

재굴림과 배치를 모두 전략 요소로 삼는다. 운이 나쁘더라도 배치와 보유 효과를 통해 결과를 개선할 수 있어야 한다.

### 3.3 주사위 면 구성

기본 주사위 면은 6종의 문양으로 시작한다.

| 문양 | 기본 효과 예시 | 역할 |
|---|---|---|
| 칼날 | 적에게 피해 3 | 공격 |
| 방패 | 방어도 3 획득 | 방어 |
| 불꽃 | 피해 2 및 화상 1 | 지속 피해 |
| 피 | 피해 4, 체력 1 소모 | 고위험 공격 |
| 사슬 | 인접한 주사위 효과 강화 | 연계 |
| 공허 | 자원 1 획득 | 특수 효과 |

각 면은 **문양과 숫자**를 함께 가진다.

- 숫자는 기본 효과의 위력을 나타낸다.
- 문양은 효과의 종류를 결정한다.
- 예: 칼날 2는 피해 2, 칼날 3은 피해 3을 준다.
- 유물이나 계약으로 숫자와 문양의 상호작용을 바꿀 수 있다.

초기 밸런스 수치는 프로토타입 테스트를 통해 조정한다.

## 4. 조합 시스템

조합은 이 게임의 핵심 시스템이다. 단순히 같은 문양이 여러 개 나오는 데서 끝나지 않도록 세 계층으로 설계한다.

### 4.1 기본 조합

| 조합 | 조건 | 효과 예시 |
|---|---|---|
| 쌍둥이 | 같은 문양 2개가 인접 | 해당 문양 효과 1회 추가 발동 |
| 삼위일체 | 같은 문양 3개가 연속 | 해당 문양의 특수 효과 발동 |
| 교차 | 공격과 방어 문양이 교차 배치 | 공격력과 방어도 보너스 |
| 연결 | 사슬이 다른 문양 사이에 배치 | 양쪽 효과 강화 |
| 완전한 균형 | 서로 다른 문양 5개 | 전체 효과 소폭 강화 |

위 조합은 초기 설계안이며 실제 판정 방식과 수치는 플레이 테스트를 거쳐 확정한다.

### 4.2 특수 조합

특정 문양의 개수나 배치 조건으로 발동하는 고급 조합이다.

- **피의 의식:** 피 문양 2개 이상이면 체력을 소모해 피해를 증폭한다.
- **공허의 군집:** 공허 문양 3개 이상이면 추가 주사위 효과를 복사한다.
- **화염 폭발:** 불꽃 문양 3개 이상이면 화상을 중첩하고 즉시 피해를 준다.

### 4.3 계약으로 생성되는 조합

계약은 기본 규칙에 없는 새로운 조합과 판정 방식을 추가한다.

| 계약 | 새롭게 생기는 규칙 |
|---|---|
| 역전의 계약 | 가장 낮은 숫자를 가장 높은 숫자로 취급 |
| 피의 계약 | 체력을 잃을 때마다 다음 칼날 피해 증가 |
| 거울의 계약 | 양 끝 주사위 효과 복제 |
| 연쇄의 계약 | 조합 발동 시 인접한 사슬도 추가 발동 |
| 공허의 계약 | 특정 조건에서 주사위 효과를 다른 효과로 대체 |

계약을 획득하면 기존에 없던 빌드 가능성이 열려야 한다. 조합은 무조건 강해지는 것만으로 설계하지 말고, 한 조합의 장점을 얻는 대신 다른 조합을 포기해야 하는 선택도 제공한다.

## 5. 시너지 및 연쇄 발동

### 5.1 핵심 차별화

일반적인 조합 보너스에서 끝나지 않고, **하나의 조합이 다른 효과를 발생시키고 그 효과가 다시 다른 효과와 연결되는 구조**를 만든다.

예시 보유 효과:

- 거울의 계약: 양 끝 주사위 효과 복제
- 연쇄의 계약: 조합 발동 시 사슬 효과 추가 발동
- 화염의 반지: 불꽃 효과 발동 시 화상 2 추가

예시 주사위 결과:

`불꽃 - 사슬 - 불꽃 - 피 - 불꽃`

가능한 처리 흐름:

1. 불꽃 3개 조건을 만족해 화염 조합 발동
2. 거울 계약으로 양 끝 불꽃 효과 복제
3. 연쇄 계약으로 사슬 효과가 불꽃 효과를 강화
4. 화염의 반지로 화상 중첩 추가

이와 같은 연쇄가 플레이어가 직접 구성한 빌드의 성과로 느껴져야 한다.

### 5.2 연쇄 발동 제한

연쇄 효과는 무한 반복이나 과도한 전투 시간을 유발할 수 있으므로 초기부터 제한 규칙을 둔다.

- 한 턴에 같은 조합은 기본적으로 1회만 발동한다.
- 복제된 효과는 다시 복제 효과를 발생시키지 않는다.
- 연쇄 효과는 최대 3단계까지 발동한다.
- 효과가 발동한 이유와 순서를 전투 로그에 표시한다.
- 피해량과 발동 횟수에 상한을 둘 수 있도록 설계한다.

전투 연출만큼이나 **왜 해당 효과가 발동했는지 이해할 수 있는 정보 표시**가 중요하다.

## 6. 성장 시스템

성장은 주사위, 유물, 계약 세 종류로 구분한다.

### 6.1 주사위 성장

주사위는 플레이어의 핵심 자산이다.

| 성장 방식 | 설명 |
|---|---|
| 면 교체 | 방패 면을 사슬 면으로 변경하는 등 특정 면 교체 |
| 숫자 강화 | 칼날 2를 칼날 4로 변경 |
| 특수 면 추가 | 특정 주사위의 면 효과 변경 |
| 저주 면 제거 | 불리한 면 제거 |
| 변형 | 불꽃 면을 독 면으로 변경하는 등 속성 변환 |

주사위마다 서로 다른 특성을 부여할 수 있다.

- 공격 주사위: 칼날 면의 피해량 증가
- 연계 주사위: 사슬 면의 효과 증가
- 저주 주사위: 강력한 효과와 불리한 효과가 함께 존재

초기에는 주사위 종류를 지나치게 늘리기보다 기본 주사위의 면을 변경하는 성장에 집중한다.

### 6.2 유물

유물은 주사위 자체보다 전투 규칙과 효과를 변경하거나 강화한다.

| 유물 | 효과 예시 | 성격 |
|---|---|---|
| 탐욕의 왕관 | 공격 조합 피해량 50% 증가, 방어 조합 방어도 30% 감소 | 공격 특화 |
| 망가진 거울 | 양 끝에 같은 문양이 배치되면 해당 효과 복제 | 배치 특화 |
| 피의 반지 | 체력을 잃을 때마다 다음 공격 피해량 증가 | 위험 감수형 |
| 속박의 사슬 | 사슬 문양이 포함된 조합 효과 강화 | 연계 특화 |

### 6.3 계약

계약은 유물과 달리 **게임 규칙 자체를 변경하는 성장 요소**다.

| 계약 | 효과 | 대가 |
|---|---|---|
| 거울 계약 | 양 끝 효과 복제 | 복제 피해 50% 감소 |
| 피의 계약 | 체력 소모로 공격력 증가 | 최대 체력 감소 |
| 역전 계약 | 낮은 숫자를 높은 숫자로 취급 | 높은 숫자 면의 효과 감소 |
| 공허 계약 | 조합 실패 시 자원 획득 | 조합 성공 시 자원 소모 |
| 탐욕 계약 | 유물 효과 2배 | 상점 가격 증가 |

계약에는 장점과 단점을 함께 부여해 선택의 무게를 만든다.

계약끼리 특별한 조합이 발생하도록 확장할 수 있지만, MVP에서는 계약 하나만으로도 충분히 흥미로운 효과를 제공하는 데 집중한다.

## 7. 빌드 방향

초기에는 네 가지 빌드 방향을 기준으로 콘텐츠를 설계한다. 플레이어가 처음부터 클래스를 고르는 방식보다는 획득한 유물과 계약에 따라 자연스럽게 빌드가 형성되는 구조를 추천한다.

### 7.1 화염 폭발형

- 불꽃 문양 중심
- 화상 중첩
- 조합 발동 시 광역 피해
- 장점: 높은 누적 피해
- 약점: 초반 화력이 약할 수 있음

### 7.2 피의 도박형

- 체력을 소모해 강력한 효과 발동
- 피 문양과 공격 문양 시너지
- 체력이 낮을수록 강해지는 유물
- 장점: 폭발적인 공격력
- 약점: 생존 위험

### 7.3 거울 복제형

- 양 끝 문양 활용
- 효과 복제와 연쇄 발동
- 배치 순서가 중요
- 장점: 높은 시너지 잠재력
- 약점: 원하는 배치가 어려움

### 7.4 사슬 연계형

- 사슬 문양 중심
- 인접 효과 강화
- 여러 조합을 연속으로 연결
- 장점: 안정적인 연계
- 약점: 단일 효과의 위력이 낮음

## 8. 맵 및 원정 구성

한 번의 원정은 3개 구역으로 구성한다.

| 구역 | 주요 적 | 특징 |
|---|---|---|
| 1구역: 계약의 지하실 | 기본 적, 미니 보스 | 기본 빌드 구성 |
| 2구역: 저주의 시장 | 정예 적, 이벤트 | 계약과 유물 조합 |
| 3구역: 악마의 심연 | 강력한 적, 최종 보스 | 완성된 빌드 검증 |

맵은 분기형으로 구성한다.

| 노드 | 기능 |
|---|---|
| 일반 전투 | 기본 보상 획득 |
| 정예 전투 | 고급 유물 획득 기회 |
| 상점 | 주사위 변경 및 유물 구매 |
| 이벤트 | 위험과 보상 중 선택 |
| 휴식 | 체력 회복 또는 주사위 강화 |
| 보스 | 구역 최종 전투 |

초기에는 맵을 복잡하게 만들지 않고 구역마다 5~7개 정도의 선택 지점을 제공한다.

---

## 9. 차별화 요소

| 요소 | 일반적인 주사위 로그라이크 | 악마의 주사위 |
|---|---|---|
| 조합 | 정해진 족보와 조합 | 계약으로 조합 규칙 변경 |
| 성장 | 숫자와 피해량 강화 | 주사위 면과 발동 규칙 변경 |
| 유물 | 능력치 및 효과 강화 | 다른 효과를 연결하는 시너지 |
| 전략 | 어떤 눈이 나올지 기대 | 눈의 배치와 연쇄 효과 설계 |
| 후반부 | 수치가 커지는 성장 | 새로운 조합 엔진 완성 |

### 9.1 조합 도감

플레이어가 발견한 조합을 자동으로 기록한다.

- 처음 발견한 조합 기록
- 특정 계약으로만 가능한 조합 기록
- 특정 조건을 만족한 특수 조합 기록
- 특정 조합으로 보스를 처치한 기록

조합 도감은 수집 욕구를 자극하고 새로운 빌드를 실험하도록 유도한다. 향후 조합 발견 수와 특수 조합 성공 수를 기반으로 업적 및 해금 요소를 추가할 수 있다.

## 10. MVP 범위

### 10.1 MVP 목표

먼저 **전투 1개 구역을 끝까지 플레이할 수 있는 프로토타입**을 만든다. 정식 출시 분량을 처음부터 제작하지 말고 핵심 전투와 시너지의 재미를 검증한다.

### 10.2 MVP 콘텐츠 목표

| 항목 | 목표 수량 |
|---|---:|
| 플레이 캐릭터 | 1종 |
| 기본 주사위 | 5개 |
| 주사위 문양 | 6종 |
| 기본 조합 | 5종 |
| 계약 | 8종 |
| 유물 | 12종 |
| 일반 적 | 4종 |
| 보스 | 1종 |
| 이벤트 | 3종 |
| 구역 | 1개 |
| 원정 플레이 시간 | 약 10~15분 |

### 10.3 반드시 구현할 기능

1. 주사위 굴리기 및 선택 재굴림
2. 최종 주사위 배치
3. 기본 조합 판정
4. 계약 효과 적용
5. 연쇄 발동 처리
6. 전투 보상 선택
7. 다음 전투 진행
8. 보스 처치 또는 사망으로 원정 종료

### 10.4 MVP에서 제외할 기능

- 여러 플레이 캐릭터
- 복잡한 스토리
- 장비 제작
- 온라인 기능
- 다중 난이도
- 대규모 영구 성장 트리
- 다수의 구역과 보스
- 대량의 적 애니메이션

영구 성장 시스템은 신중하게 접근한다. 로그라이크의 재미가 영구 능력치 증가에 지나치게 의존하면 반복 플레이가 빌드 실험보다 수치 노가다로 변할 수 있다.

### 10.5 개발 단계

| 단계 | 작업 | 검증 목표 |
|---|---|---|
| 1단계 | 주사위 굴림, 재굴림, 배치, 기본 피해 및 방어 | 기본 전투가 재미있는가 |
| 2단계 | 기본 조합 5종 및 조합 발동 UI | 조합을 만들고 싶어지는가 |
| 3단계 | 계약 8종, 유물 12종, 연쇄 효과 | 빌드와 시너지가 달라지는가 |
| 4단계 | 적, 보스, 보상, 상점, 이벤트 | 원정 흐름이 성립하는가 |
| 5단계 | 주사위 애니메이션, 이펙트, 사운드, UI | 피드백이 명확하고 만족스러운가 |
| 6단계 | 반복 플레이 테스트 및 밸런스 조정 | 다시 플레이할 이유가 있는가 |

## 11. 정식 출시 목표 콘텐츠

MVP의 재미가 검증된 이후 정식 출시 분량을 확장한다.

| 콘텐츠 | 정식 출시 목표 |
|---|---:|
| 플레이 캐릭터 | 3종 |
| 주사위 종류 | 15~20종 |
| 문양 | 8~10종 |
| 조합 | 20~30종 |
| 계약 | 30~40종 |
| 유물 | 60~80종 |
| 일반 적 | 20종 |
| 보스 | 6종 |
| 구역 | 3개 |
| 이벤트 | 20종 이상 |
| 난이도 | 기본 + 도전 단계 |

수량 자체가 재미를 보장하지 않는다. 서로 다른 효과가 실제로 새로운 빌드를 만들어내는지가 더 중요하다.

## 12. 주요 위험 요소 및 대응

| 위험 요소 | 발생할 수 있는 문제 | 대응 방향 |
|---|---|---|
| 조합이 너무 복잡함 | 플레이어가 규칙을 이해하지 못함 | 발동 조건과 결과를 항상 표시 |
| 운의 영향이 너무 큼 | 전략적 선택이 무의미해짐 | 재굴림과 배치의 영향 강화 |
| 특정 빌드 독점 | 매번 같은 조합만 선택 | 빌드별 장단점과 적 대응 추가 |
| 연쇄 효과 과다 | 전투가 지나치게 길어짐 | 발동 제한과 효과 압축 |
| 콘텐츠 제작 부담 | 주사위와 유물 수가 계속 증가 | 효과 조합형 설계와 재사용 가능한 규칙 시스템 |
| 효과 판정 불투명 | 플레이어가 결과를 이해하지 못함 | 전투 로그와 발동 순서 표시 |

가장 큰 위험은 조합 수가 적은 것이 아니라, 조합이 너무 쉽게 정답으로 고정되는 것이다. 같은 상황에서도 어떤 계약을 선택했는지에 따라 유리한 조합이 달라져야 하며, 적의 특성도 빌드 선택에 영향을 줘야 한다.

## 13. 우선 확정할 전투 규칙

실제 개발에 들어가기 전에 다음 세 가지를 확정한다.

### 13.1 주사위 배치 방식

| 선택지 | 설명 |
|---|---|
| 자유 배치 | 최종 주사위 5개의 순서를 원하는 대로 변경 |
| 고정 배치 | 굴린 순서 그대로 판정 |
| 제한 배치 | 주사위 2개까지만 위치 변경 |

**초기 추천: 자유 배치**

주사위 결과를 단순히 받아들이는 것이 아니라, 결과를 조립해 시너지를 만드는 게임이라는 정체성이 잘 살아난다.

### 13.2 재굴림 방식

| 선택지 | 설명 |
|---|---|
| 1회 재굴림 | 원하는 주사위만 선택해 다시 굴림 |
| 2회 재굴림 | 더 전략적이지만 전투가 길어질 수 있음 |
| 자원 방식 | 재굴림할 때마다 자원 소모 |

**초기 추천: 1회 재굴림**

짧고 명확한 턴 구조를 유지하면서도 선택의 여지를 제공한다.

### 13.3 조합 판정 방식

| 선택지 | 설명 |
|---|---|
| 혼합형 | 문양, 순서, 숫자 조건을 모두 활용 |
| 문양 중심 | 같은 문양과 문양 간 관계가 핵심 |
| 숫자 중심 | 합계, 연속 숫자, 홀짝 등이 핵심 |

**초기 추천: 혼합형**

문양으로 기본 시너지를 만들고 숫자와 순서가 특정 계약 및 고급 조합에 영향을 주도록 설계한다.

## 14. 최종 방향 요약

### 게임의 핵심 문장

> **굴림은 운명, 조합은 실력.**

### 핵심 설계 원칙

1. 전투가 재미있어야 한다. 주사위 굴림과 배치만으로도 고민할 거리가 있어야 한다.
2. 조합을 발견하는 재미가 있어야 한다. 새로운 계약이 새로운 플레이 방식을 열어야 한다.
3. 시너지가 폭발해야 한다. 후반부에는 플레이어가 자신이 만든 엔진의 위력을 체감해야 한다.
4. 반복 플레이의 이유가 있어야 한다. 다른 계약과 유물을 조합해 새로운 빌드를 실험하고 싶어야 한다.

### 초기 권장 설정

- 자유 배치
- 1회 재굴림
- 문양·숫자·순서를 활용하는 혼합형 조합
- 주사위 5개
- 기본 문양 6종
- 계약을 통한 규칙 변경
- 연쇄 효과 최대 3단계
- MVP는 1개 구역과 보스 1종으로 핵심 재미 검증

**개발 최우선 과제:** 아트와 콘텐츠를 대량 제작하기 전에, 주사위 5개를 굴리고 배치해 조합과 시너지를 만드는 전투 프로토타입부터 완성한다.
