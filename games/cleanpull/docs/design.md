# 식탁보 빼기 (Clean Pull) 게임 기획서 v1

> **한 줄 소개:** 차려진 식탁에서 식탁보만 한 번에 확 빼는 묘기. 그릇을 더 올릴수록 점수가 뻥튀기되고, 하나라도 떨어지면 와장창.
> **공통 기준:** [게임 공통 가이드](../../../docs/game-guide.md)(로그라이크 구조, 콘솔식 큰 화면, 처음 할 때 단계별 안내)를 따른다.
> **키워드:** 2D 물리 · 한 방 손맛 · 운 걸기 · 발라트로식 점수 폭발 · 슬로모션 · 관객 환호

---

## 1. 개요

### 1.1 콘셉트

떠돌이 묘기꾼이 동네 저녁 식탁에서 시작해 결혼식 피로연, 고급 레스토랑, 달리는 기차 식당칸까지 무대를 넓혀 간다. 할 줄 아는 건 하나, **식탁보 빼기**다.

한 번 당기는 데 1초. 성공하면 슬로모션 속에 그릇이 제자리에 "툭" 내려앉고 관객이 터진다. 실패하면 접시가 날아가고 와인이 쏟아진다. 그 1초 전에 "하나 더 올릴까?"를 고민하는 게 이 게임의 전부다.

### 1.2 기본 사양

| 항목 | 방향 |
|---|---|
| 장르 | 싱글 묘기 로그라이크(로그라이트), 한 판 15~25분. 투어마다 그릇 후보·무대 흔들림·가게 카드가 seed로 바뀐다 |
| 플랫폼 | PC / Steam (Steam Deck 대응 목표), 웹 미리보기. 나중에 모바일(밀어 당기기 터치가 잘 맞음) |
| 그래픽 | 2D 옆모습 식탁 한 화면. Kenney CC0 Food Kit·Furniture Kit 3D 모델을 2D로 구워 쓴다 |
| 조작 | 마우스 하나: 식탁보 끝을 잡고 휙 당긴다. 컨트롤러는 트리거 + 스틱 튕기기 |
| 언어 | 한국어, 영어 |

### 1.3 핵심 재미

1. **한 방 손맛:** 손목 스냅 하나로 결과가 정해진다. 빠르고 수평으로 당길수록 잘 빠진다.
2. **운 걸기:** 당기기 전에 무엇을 더 올릴지 고른다. 와인잔 하나가 배수를 두 배로 만들지만, 넘어지기도 제일 쉽다.
3. **점수 폭발:** 그릇마다 박수(기본 점수)가 붙고, 묘기 카드와 아슬아슬 보너스가 환호(배수)를 쌓는다. 박수 × 환호가 한 번에 터지는 연출이 보상이다.
4. **아슬아슬:** 식탁 끝 1cm에서 멈춘 잔은 슬로모션과 함께 큰 보너스. 실패와 대박이 같은 자리에 있다.

### 1.4 비슷한 게임과 차별점

| 게임 | 공통점 | 이 게임의 차이 |
|---|---|---|
| Balatro | 점수 × 배수, 규칙을 깨는 카드 | 카드 대신 실제 손 조작 한 번이 점수를 만든다 |
| Table Flip Simulator, Flip the Table | 식탁 소재 | 뒤엎어 부수는 게임. 이 게임은 **아무것도 안 떨어뜨리는** 게 목표 |
| Hold The Plates | 접시 | 떨어지는 접시를 받는 아케이드. 이 게임은 식탁보 빼기 한 동작 |
| 「Jenga」류 | 무너질까 조마조마 | 쌓기가 아니라 한순간 빼내기, 결과가 1초 안에 나온다 |

Steam에서 "tablecloth", "table cloth", "clean pull", "tablecloth trick"으로 검색했을 때 같은 소재 게임은 찾지 못했다(2026-11 Steam 상점 검색 기준).

## 2. 한 판의 흐름

```
투어 = 무대 8개
무대 = 목표 점수 + 당기기 3번
당기기 1번 = [차리기] → [당기기] → [정산]
무대 사이 = [가게]에서 묘기 카드·식탁보·소품 구매
```

- **차리기:** 이번 무대 식탁에 놓을 그릇 후보 5개가 나온다. 원하는 만큼 원하는 자리에 올린다. 많이, 높이, 끝 쪽에 올릴수록 점수가 크다.
- **당기기:** 식탁보 끝을 잡고 휙 당긴다. 슬로모션으로 결과가 나온다.
- **정산:** 제자리에 남은 그릇만 점수가 된다. 떨어진 그릇은 0점이고 "깨진 그릇" 벌점이 쌓인다.
- 3번 안에 목표 점수를 넘기면 다음 무대. 못 넘기면 투어 끝(로그라이트).
- 무대마다 목표 점수는 대략 ×1.6씩 오른다. 8번째 무대는 **본 공연**(결혼식 케이크 탑).
- 가게에서는 묘기 카드 **3장 중 1장**을 고른다(돈이 남으면 더 산다). 투어가 끝나면 번 평판으로 새 그릇·카드·무대가 풀린다.

## 3. 당기기

### 3.1 조작

1. 식탁 오른쪽에 늘어진 식탁보 끝을 마우스로 잡는다.
2. 잡은 채로 빠르게 튕기듯 당기고 놓는다.
3. 마지막 0.1초의 **속도**와 **각도**로 결과가 정해진다.

| 요소 | 좋은 쪽 | 나쁜 쪽 |
|---|---|---|
| 속도 | 빠를수록 그릇이 덜 끌려온다 | 느리면 그릇이 같이 딸려 온다 |
| 각도 | 수평~살짝 아래 | 위로 당기면 그릇이 튀어 오른다 |
| 흔들림 | 곧게 한 번에 | 중간에 멈칫하면 그 순간 마찰이 커진다 |

- 손목 게이지: 당기는 동안 식탁 바로 아래에 화면 폭 절반 크기의 굵은 속도 게이지가 뜬다. 초록 구간을 넘기면 "쫙!" 소리가 난다. 처음 하는 사람도 게이지만 보고 감을 잡는다.

### 3.2 판정 모델 (결정론)

게임 규칙은 Godot 물리 엔진이 아니라 직접 만든 `PullSim`이 계산한다. 같은 입력이면 같은 결과가 나오고, 테스트로 검증할 수 있다. 무너지는 장면 연출만 Godot 물리로 그린다.

```
그릇마다:
  천이 그릇 밑을 지나가는 시간  t = 천 길이(그릇 아래) / 당기는 속도
  천과 함께 끌려가는 거리      d1 = ½ · μ천 · g · t²
  천이 빠진 뒤 식탁 위 미끄러짐 d2 = (μ천 · g · t)² / (2 · μ식탁 · g)
  이동 거리                    d = d1 + d2
  넘어짐: 가속도 μ천·g × 높이/밑면 폭 > 넘어짐 기준 → 넘어짐
  각도가 위쪽이면 들림 성분이 생겨 넘어짐 기준이 낮아진다
결과:
  d가 식탁 끝을 넘으면 → 떨어짐
  d가 옆 그릇과 겹치면 → 부딪힘(둘 다 흔들림 판정)
  넘어지면 → 쏟아짐(내용물 있는 그릇은 이웃 그릇에 벌점)
```

### 3.3 아슬아슬과 완벽

| 판정 | 조건 | 효과 |
|---|---|---|
| 완벽 | 이동 거리 < 0.5cm | 환호 +1 |
| 아슬아슬 | 식탁 끝까지 2cm 안에서 멈춤 | 환호 ×1.5, 슬로모션 0.8초, 관객 "오오오" |
| 기적 | 넘어질 뻔하다 다시 섰음(기울기 기준 90~100%) | 환호 ×2, 화면 흔들림 |

## 4. 점수

```
점수 = 박수 합 × 환호 합
박수: 남은 그릇마다 그릇 박수 + 높이 보너스
환호: 1 + 완벽·아슬아슬·기적 + 묘기 카드
```

점수는 그릇 하나씩 차례로 올라가는 연출로 보여 준다. 마지막에 박수 × 환호가 곱해지는 순간 숫자가 커지며 터진다.

## 6. 묘기 카드 (가게, 최대 5장 장착)

발라트로의 조커처럼 규칙을 비트는 카드다. MVP 20종 중 예시:

| 카드 | 효과 |
|---|---|
| 왁스 바른 식탁보 | 천 마찰 −30% |
| 촛불 공연 | 불 켜진 촛대가 남으면 환호 ×2 |
| 한 손 묘기 | 당기기 1번 줄고, 환호 +3 |
| 눈가리개 | 속도 게이지가 안 보이지만 환호 ×3 |
| 접시 탑 | 쌓은 접시 한 장마다 환호 +0.5 |
| 고양이 관객 | 아슬아슬이 나올 때마다 박수 +30 |
| 할머니 축복 | 도자기가 깨져도 한 번은 평판이 안 떨어짐 |
| 앙코르 | 무대 마지막 당기기 점수 ×1.5 |
| 고무 식탁 | 식탁 마찰 +50%: 이동이 짧아짐 |
| 쇼맨십 | 당기기 전 관객에게 인사(시간 소모)하면 다음 환호 +1, 연속으로 쌓임 |

식탁보도 바꿀 수 있다: 실크(마찰 낮음, 짧음), 레이스(길어서 시간 김), 비닐(마찰 매우 낮음, 대신 정전기로 가벼운 그릇이 따라옴).

## 8. MVP 범위

### 8.1 목표
웹에서 투어 1회(8무대)를 끝까지 할 수 있고, "한 판 더"가 나오는지 확인한다.

### 8.2 콘텐츠 수량
- 그릇 12종, 묘기 카드 20종, 식탁보 3종, 무대 4곳

### 8.3 반드시 구현할 것
- `PullSim` 결정론 판정과 테스트
- 슬로모션, 아슬아슬 연출, 점수 폭발 연출, 와장창 물리 연출
- 첫 판 단계별 안내(12.3): 접시 1개 → 와인잔 추가 → 속도 게이지, 세 번 당기기로 끝
- 효과음(Kenney CC0)과 관객 반응

### 8.4 MVP에서 뺄 것
- 온라인 순위표, 일일 도전, 모바일 빌드, 컨트롤러 진동, 컨트롤러로 당기기(메뉴·카드 고르기는 패드로도 된다)

## 12. 화면과 안내

### 12.1 당기기 화면

| 자리 | 보이는 것 | 글자 |
|---|---|---|
| 위 가운데 | 지금 할 일 한 줄 (64px) | "끝을 잡고 휙!" |
| 왼쪽 위 | 무대 길: 무대 8개 아이콘, 지금 무대가 커지고 빛남 | 없음 |
| 오른쪽 위 | 남은 당기기: 식탁보 아이콘 3개, 쓰면 회색 | 없음 |
| 가운데 | 식탁과 그릇. 식탁보 끝은 빛나며 흔들리고, 손가락이 휙 끄는 동작을 반복 | 없음 |
| 식탁 아래 | 큰 속도 게이지(빨강 → 초록), 바늘이 실시간으로 움직임 | 없음 |
| 아래 가운데 | 목표 점수 막대: 이번 무대 목표까지 얼마나 찼는지 | 숫자만 |

### 12.2 결과 화면

- 성공: 슬로모션 → 화면 가운데에 큰 도장 「CLEAN!」(그림 글자)이 쾅 찍힌다 → 남은 그릇 위로 박수 숫자가 하나씩 튀어 오른다 → 박수 × 환호가 곱해지며 120px 이상 숫자가 터진다 → 관객 실루엣이 일어나 환호한다.
- 실패: 깨지는 순간 화면 흔들림, 깨진 그릇 위에 빨간 금 간 접시 아이콘이 뜬다. 글자 태그(「와장창」, 「넘어짐」)는 쓰지 않는다.
- 다음 행동은 큰 그림 버튼 2~3개(높이 160px 이상):

| 버튼 | 그림 | 한 단어 |
|---|---|---|
| 다음 당기기 | 오른쪽 화살표 붙은 식탁 | 다음 |
| 다시 (연습 모드만) | 되감기 화살표 | 다시 |
| 그만두기 | 집 | 나가기 |

### 12.3 첫 판 안내

처음 투어를 시작하면 자동으로 나온다. 화면을 어둡게 하고 대상 하나만 밝힌다.

| 단계 | 밝히는 곳 | 말풍선 (그림 + 한 줄) | 넘어가는 조건 |
|---|---|---|---|
| 1 | 식탁보 끝 | 손가락 그림 + "여기를 잡아요" | 실제로 잡음 |
| 2 | 식탁보 끝 → 오른쪽 | 휙 끄는 화살표 + "오른쪽으로 휙!" | 당기기 끝 |
| 3 | 속도 게이지 | 초록 구간 반짝 + "초록까지 빠르게" | 화면 누르기 |
