# 식탁보 빼기 (`cleanpull`)

**식탁보 빼기 (Clean Pull)** — 차려진 식탁에서 식탁보만 한 번에 확 빼는 묘기 로그라이트. 많이 올릴수록 배수가 쌓이고, 하나라도 떨어지면 와장창 (Godot 4, Steam).

- 웹 미리보기: https://minthold-cleanpull.web.app (`develop` 머지 시 자동 배포)

- 기획서: [docs/design.md](docs/design.md)
- 개발 단계: [docs/plan.md](docs/plan.md)

구조와 개발 환경은 [`games/rooster/docs/architecture.md`](../rooster/docs/architecture.md)와 같은 규칙을 따른다(Godot 4.7.x, gdUnit4, 규칙 로직과 화면 분리).
