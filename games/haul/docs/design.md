# 막차 택배 (Haul Order) 게임 기획서 v1

> **한 줄 소개:** 아침 7시 전까지 새벽 배송을 끝내야 하는 택배 기사가 되어, 내릴 순서를 거꾸로 계산하며 트럭 짐칸을 채우는 적재 퍼즐 로그라이트.
> **키워드:** 2D · 적재 퍼즐 · 나중에 실은 짐이 먼저 나온다 · 하루 단위 로그라이트 · 트럭 개조

---

## 1. 개요

### 1.1 콘셉트

플레이어는 새벽 배송 기사다. 밤 12시에 물류센터에서 그날 배송할 상자를 받아 1톤 트럭 짐칸에 싣고, 정해진 순서대로 집을 돌며 상자를 내린다.

짐칸 문은 뒤쪽 하나뿐이다. **먼저 들를 집의 상자가 문 쪽에, 마지막 집의 상자가 안쪽에 있어야 한다.** 순서가 꼬이면 앞을 막은 상자를 길에 꺼내 놓았다가 다시 실어야 하고, 그만큼 시간이 흐른다. 아침 7시가 넘으면 늦은 배송이 되어 평점이 깎인다.

실력이 드러나는 곳은 손 빠르기가 아니라 **상차할 때 미래를 얼마나 내다보느냐**다.

### 1.2 기본 사양

| 항목 | 방향 |
|---|---|
| 장르 | 싱글 적재 퍼즐 + 로그라이트 |
| 플랫폼 | PC / Steam (Steam Deck 대응 목표), 개발 중에는 웹 미리보기 |
| 그래픽 | 2D 플랫 일러스트, 밤 도시(가로등 주황 + 남색) |
| 화면 | 짐칸을 옆에서 본 단면 1개 + 배송 경로 띠 |
| 조작 | 마우스 드래그, 회전(우클릭 또는 R), 컨트롤러 대응 |
| 1회 플레이 | 약 20~30분 (근무 5일) |
| 언어 | 한국어, 영어 (처음부터 번역 테이블로 관리) |

### 1.3 핵심 재미

1. **거꾸로 생각하기:** 싣는 순서와 내리는 순서가 반대다. "세 번째 집 상자를 지금 어디에 넣어야 하지?"를 계속 고민한다.
2. **모양 맞추기:** 상자는 여러 칸짜리 모양(1×1, 2×1, L자, 2×2 등)이다. 빈틈 없이 채우면 더 많이 싣고, 더 많이 벌 수 있다.
3. **조건 얹기:** 깨지기 쉬운 상자 위에는 무거운 걸 올릴 수 없고, 냉동품은 늦게 내리면 녹는다. 단순한 테트리스가 아니라 조건이 겹치는 퍼즐이 된다.
4. **계획이 틀어지는 순간:** 고객 부재로 상자가 다시 돌아오거나, 중간에 반품 수거가 끼어든다. 완벽하게 실어 둔 짐칸을 그 자리에서 고쳐야 한다.

### 1.4 비슷한 게임과 차별점

| 게임 | 공통점 | 이 게임의 차이 |
|---|---|---|
| Tetris | 모양 블록 채우기 | 줄을 지우는 게 아니라 **나중에 꺼낼 순서**가 목적 |
| Backpack Battles | 가방 공간 퍼즐 | 전투 없음. 공간 + **시간 순서** 퍼즐 |
| Parcel Packing Simulator | 택배 소재 | 포장 시뮬이 아니라 트럭 적재와 배송 순서 |
| Fridge Organizer | 먼저 넣은 걸 먼저 꺼내는 정리 규칙 | 냉장고 정리가 아니라 **배송 경로**와 시간 제한, 로그라이트 성장 |
| Unpacking | 일상 소재, 짐 정리 | 이야기 대신 점수·성장 반복 플레이 |

Steam에서 "truck packing", "loading puzzle", "cargo puzzle"로 검색했을 때 적재 순서 퍼즐은 찾지 못했다(2026-11 Steam 상점 검색 기준).

## 2. 한 판의 흐름

```
[1일차] 상차 → 배송 → 정산 → 트럭 개조
[2일차] 상차 → 배송 → 정산 → 트럭 개조
…
[5일차] … 명절 물량(상자 수 2배)
→ 평점이 기준 이상이면 정규직 전환(승리), 아니면 계약 종료(패배)
```

- **평점(별 5개 만점)**이 목숨 역할이다. 늦은 배송, 파손, 녹은 냉동품마다 깎이고, 하루가 끝날 때 3.0 아래면 그 자리에서 계약이 끝난다.
- **돈**은 배송 수당으로 번다. 정산 화면에서 트럭 개조와 도구에 쓴다.
- 1일차는 연습처럼 쉽고, 5일차는 명절 물량이다.
- 하루 사이에 **사건**(이벤트) 1개가 나올 수 있다. 예: "동료가 아파서 구역 하나를 더 맡아 달라고 한다."

## 3. 상차 (물류센터)

- 화면 위에 오늘의 **배송 경로**가 집 순서대로 나온다. 집마다 색과 번호가 있고, 그 집 상자에도 같은 색·번호가 붙어 있다.
- 화면 아래 컨베이어에 상자가 쌓여 있다. 드래그해서 짐칸에 넣는다.
- **상자는 문(오른쪽)에서 밀어 넣는다.** 문에서 그 자리까지 가는 길이 막혀 있으면 놓을 수 없다.
- **중력이 있다.** 놓은 상자는 아래로 떨어져 자리를 잡는다. 공중에 뜬 채로 둘 수 없다.
- 상차 시간은 시계로 1시간(밤 12시~1시)이다. 상자 하나를 놓을 때마다 시계가 흐른다(5.1). 상차 중에는 되돌리기를 마음껏 할 수 있다.
- 다 싣지 못한 상자는 놓고 갈 수 있다. 대신 그 집은 배송 실패로 평점이 깎인다.

## 4. 짐칸

### 4.1 모양

- 옆에서 본 단면 격자다. 기본은 **가로 8 × 세로 4칸**. 왼쪽 끝이 운전석 쪽 벽, 오른쪽 끝이 뒷문이다.
- 상자는 1~4칸짜리 모양이다. MVP 모양 8종: 1×1, 2×1, 3×1, 2×2, L자, 역L자, T자, 1×2(세로).
- 상자를 돌릴 수 있다. 단, "이쪽이 위로" 표시가 있는 상자는 돌릴 수 없다.

### 4.2 꺼내기 규칙

상자를 꺼낼 수 있는 조건은 둘이다.

1. **위가 비어 있다.** 그 상자 바로 위 칸에 다른 상자가 없다.
2. **문까지 길이 열려 있다.** 그 상자가 오른쪽으로 미끄러져 문 밖으로 나갈 때 부딪히는 상자가 없다.

꺼내면 그 위에 있던(받침을 잃은) 상자는 아래로 떨어진다. 떨어지는 상자가 깨지기 쉬운 상자면 파손된다.

### 4.3 상자 속성 (MVP)

| 속성 | 표시 | 규칙 |
|---|---|---|
| 일반 | 없음 | 제한 없음 |
| 깨지기 쉬움 | 유리잔 | 위에 다른 상자를 올리면 파손. 한 칸 넘게 떨어져도 파손 |
| 무거움 | 쇳덩이 | 반드시 바닥 줄 또는 다른 무거운 상자 위에만 놓을 수 있음 |
| 냉동 | 눈송이 | 경로 앞쪽 절반 안에 내려야 함. 넘기면 녹아서 평점 감점 |
| 이쪽이 위로 | 화살표 | 돌릴 수 없음 |

## 5. 배송

### 5.1 시간

- 시간은 실시간이 아니라 **행동마다 흐른다.** 퍼즐을 천천히 생각해도 손해가 없다.

| 행동 | 걸리는 시간 |
|---|---:|
| 상자 하나 꺼내서 배달 | 3분 |
| 막고 있는 상자를 길에 꺼내 놓기 | 2분 |
| 길에 놓은 상자 다시 싣기 | 2분 |
| 다음 집까지 운전 | 경로마다 5~15분 |

- 아침 7시를 넘긴 배송은 늦은 배송이다. 1건마다 평점 -0.2.

### 5.2 한 집에서 하는 일

1. 트럭이 집 앞에 서면 그 집 상자가 깜빡인다.
2. 바로 꺼낼 수 있으면 클릭 한 번으로 배달한다.
3. 막혀 있으면 막은 상자를 하나씩 길에 꺼낸다(임시 보관 칸 최대 4개). 배달 후 길에 둔 상자를 다시 싣는다. 이때 원래와 다른 자리에 실어도 된다. 꼬인 짐칸을 고칠 기회다.
4. 다음 집으로 출발한다.

### 5.3 변수 (MVP)

| 변수 | 내용 |
|---|---|
| 고객 부재 | 상자를 내리지 못하고 다시 실어야 한다. 경로 끝에 재방문이 생긴다 |
| 반품 수거 | 그 집에서 상자를 하나 받아 짐칸 빈 곳에 실어야 한다. 물류센터로 돌아갈 때까지 내릴 수 없다 |
| 급정거 | 아래가 비어 있는 상자가 떨어진다. 정리를 대충 하면 손해 |

## 6. 정산과 성장

### 6.1 정산

- 배송 1건당 기본 수당. 정시 배송 보너스, 무파손 보너스가 붙는다.
- 평점은 그날 결과에 따라 오르내린다(만점 5.0, 시작 4.0).

### 6.2 트럭 개조 (MVP 8종)

| 개조 | 효과 |
|---|---|
| 짐칸 연장 | 가로 +1칸 |
| 높은 지붕 | 세로 +1칸 |
| 옆문 | 지정한 2열은 위가 비어 있으면 옆으로 바로 꺼낼 수 있음 |
| 선반 | 한 줄에 고정 선반. 위아래 상자가 서로 받치지 않음(낙하 없음) |
| 냉장칸 | 안쪽 2×2칸에 둔 냉동품은 녹지 않음 |
| 완충재 | 하루 1번 파손 무효 |
| 대차 | 길에 꺼내 놓기·다시 싣기 시간 1분으로 |
| 내비게이션 | 운전 시간 -20% |

### 6.3 계약 (선택형 규칙)

정산 때 계약 1개를 고를 수 있다. 이득과 대가가 함께 있다.

- 예: "가구점 전속: 길쭉한 3×1 상자가 많아진다. 수당 +30%."
- 예: "수산시장: 냉동품이 절반. 냉장칸 무료 설치."
- 예: "야간 할증: 출발 시간이 30분 늦어진다. 수당 +25%."

## 7. 반복 플레이

- 하루마다 경로와 상자가 시드로 새로 만들어진다.
- 승리하면 다음 난이도(구역)가 열린다: 주택가 → 아파트 단지(층이 높아 배달 시간 증가) → 시장(냉동품 많음) → 산동네(운전 시간 김).
- 기록: 최고 평점, 무파손 연속 일수, 하루 최대 배송 수.

## 8. MVP 범위

### 8.1 목표

**근무 5일 한 판을 끝까지 할 수 있는 프로토타입.** 아트는 단색 상자 + 번호로 시작한다.

### 8.2 콘텐츠 수량

| 항목 | MVP | 정식 출시 목표 |
|---|---:|---:|
| 상자 모양 | 8종 | 15종 |
| 상자 속성 | 5종 | 10종 |
| 트럭 개조 | 8종 | 25종 |
| 계약 | 5종 | 20종 |
| 사건 | 3종 | 20종 |
| 구역 | 1 | 4 |
| 1판 시간 | 15~20분 | 20~30분 |

### 8.3 반드시 구현할 것

1. 짐칸 격자, 문에서 밀어 넣기, 중력
2. 꺼내기 규칙(위가 비어 있음 + 문까지 길)
3. 상차 화면, 되돌리기
4. 배송 화면: 꺼내기, 길에 꺼내 놓기, 다시 싣기
5. 행동별 시간, 아침 7시 제한
6. 상자 속성 5종
7. 변수 3종(부재, 반품 수거, 급정거)
8. 정산, 트럭 개조, 평점, 승리/패배
9. 저장·이어하기, 시드 고정

### 8.4 MVP에서 뺄 것

구역 2~4, 일일 시드, 리더보드, 업적, 클라우드 저장, 운전 장면 연출, 일러스트 본작업.

## 9. 위험 요소

| 위험 | 문제 | 대응 |
|---|---|---|
| 정답 하나짜리 퍼즐 | 한 번 풀면 끝 | 매일 시드로 경로·상자 생성, 변수와 계약으로 매번 다른 조건 |
| 풀 수 없는 날 | 운 나쁘면 아무리 잘 실어도 늦음 | 헤드리스 풀이기로 생성된 날마다 "최선이면 몇 시에 끝나는지" 확인, 여유 시간이 없으면 다시 생성 |
| 조작 피로 | 상자 수십 개를 하나하나 드래그 | 칸 자석 맞춤, 회전 단축키, 상차 중 무제한 되돌리기 |
| 규칙이 안 보임 | 왜 못 꺼내는지 모름 | 꺼낼 수 없는 상자 위에 막고 있는 상자를 빨갛게 표시 |
| 너무 딱딱함 | 퍼즐만 있으면 심심함 | 고객 쪽지("문 앞에 두세요, 강아지 짖어요"), 새벽 도시 분위기, 하루 끝 정산 연출 |

## 10. 제목

**확정: 「막차 택배」 / Haul Order**

- "Haul Order"는 게임 용어 "Load Order"(불러오는 순서)를 비튼 말이다. 실은 순서가 곧 게임이라는 뜻이다. Steam에서 같은 이름은 찾지 못했다(2026-11 기준).
- 검토했던 다른 후보: Last Load(빨래방 공포 게임이 이미 있음), Drop Order(같은 이름 게임 있음), Load Order(모드 관리 용어라 검색이 묻힘).
- 코드명은 `haul`(`games/haul/`, Firebase 사이트 `minthold-haul`).

## 12. 아트 가이드 (프로토타입 기준)

- **방향:** 새벽 도시. 남색 하늘, 가로등 주황, 골판지 갈색 상자. 실루엣이 단순한 플랫 일러스트.
- **색상표:** 새벽 남색 `#1B2333`, 깊은 남색 `#0F1520`, 가로등 주황 `#F2A541`, 골판지 `#C8955C`, 테이프 `#E8D9B5`, 경고 빨강 `#E0523F`, 냉동 하늘색 `#7CC6E8`.
- **집 색:** 배송 순서를 구분하는 색 8개는 색약에서도 구분되도록 번호를 함께 쓴다.
- **상자:** 골판지 질감 + 테이프 한 줄 + 송장 스티커(집 번호). 속성은 큰 아이콘으로 한눈에 보이게.
