# 강호 객잔 (Jianghu Inn) 게임 기획서 v1

> **한 줄 소개:** 이름 없는 협객이 되어 강호를 떠돈다. 초식 카드를 정해진 순서로 이어 비기를 터뜨리고, 객잔에서 술 한잔과 소문으로 다음 길을 고른다.
> **키워드:** 전투 덱빌딩 · 초식 연계 · 비급 · 문파 · 객잔 · 정파와 사파

공통 기준(로그라이트 구조, 콘솔식 큰 화면, 단계별 안내)은 [`docs/game-guide.md`](../../../docs/game-guide.md)를 따른다. 이 문서는 이 게임에서 정하는 것만 적는다.

---

## 1. 개요

### 1.1 콘셉트

무림맹주가 독살당했다. 범인으로 몰린 건 하필 내가 속한 작은 문파. 누명을 벗으려면 강남에서 중원을 지나 천산까지 가서, 각 문파 장문인에게 직접 진실을 물어야 한다. 길은 멀고, 쉴 곳은 길목마다 있는 객잔뿐이다.

### 1.2 기본 사양

| 항목 | 방향 |
|---|---|
| 장르 | 1인 전투 덱빌딩 로그라이트. 한 판(런) 40~50분 |
| 전체 플레이 | 첫 완주까지 4~6시간, 문파 6개 모두 완주 15시간 이상, 그 뒤 마두 단계·끝없는 강호 |
| 플랫폼 | PC / Steam(Steam Deck), 웹 미리보기. 나중에 모바일 |
| 그래픽 | 2D 옆모습 대결 화면. 수묵화 느낌의 도형 그림, 결마다 색(강 붉음·유 푸름·쾌 노랑). Kenney CC0 팩 보조 |
| 조작 | 마우스·터치·패드: 카드 고르기 → 대상 고르기 |
| 언어 | 한국어, 영어 |

### 1.3 핵심 재미

1. **초식 잇기:** 카드마다 결(강·유·쾌)이 있다. 비급에 적힌 순서(예: 쾌 → 쾌 → 강)대로 내면 연계가 오르고, 끝까지 이으면 비기가 터진다. 손패 5장으로 이번 턴에 무엇을 이을지가 퍼즐이다.
2. **비급 모으기:** 비급(유물 역할)이 연계 순서와 보상을 정한다. 비급 3권이 서로 겹치는 순서를 가지면 한 턴에 비기가 연달아 터진다.
3. **문파 빌드:** 문파마다 시작 덱, 결 비율, 고유 규칙이 다르다. 같은 강호라도 소림과 당문은 전혀 다른 게임이다.
4. **위력 폭발:** 피해 = 초식 위력 × 연계 배수. 비기가 터지는 순간 화면이 먹물로 갈라진다.

### 1.4 비슷한 게임과 차별점

| 게임 | 공통점 | 이 게임의 차이 |
|---|---|---|
| Slay the Spire | 갈림길 지도, 적 의도 표시, 유물, 보스 | 카드를 **내는 순서**가 점수다. 유물 대신 **비급**이 연계 순서를 정한다 |
| 무협 RPG류 | 문파, 비급, 정사 | 육성 대신 한 판짜리 덱 빌드 |
| Balatro | 기본 × 배수 폭발 | 점수가 아니라 적과 겨루는 전투 |

Steam 검색(2026-11)에서 "Jianghu Inn"으로 나오는 게임은 없었다.

## 2. 한 판의 흐름

```
런 = 3막
  1막 강남(점창·아미 장문인 중 하나) → 2막 중원(무당·소림 중 하나) → 3막 천산(마교 교주)
막 = 갈림길 지도 15칸 → 막 보스(장문인)
```

| 칸 | 내용 |
|---|---|
| 싸움 | 산적·낭인·자객. 이기면 카드 3장 중 1장, 은자 |
| 강적 | 이름난 고수. 어렵지만 비급 1권 |
| 객잔 | 이 게임의 쉬는 곳·가게(아래 3장) |
| 기연 | 이벤트. 절벽 아래 동굴, 다친 노인, 수상한 상인 |
| 보물 | 비급 또는 은자 |
| 막 보스 | 장문인. 막마다 2~3명 중 하나 |

- 체력이 0이 되면 런이 끝난다. 3막 마교 교주를 꺾으면 누명을 벗고 완주다. 그 뒤 **끝없는 강호**로 계속할 수 있다.

## 3. 전투

### 3.1 기본 규칙

- 턴마다 카드 5장을 뽑고 **내공 3**을 받는다. 카드마다 내공 비용이 있다.
- 적 머리 위에 **의도**(다음 턴 공격·방어·특수)가 보인다.
- 카드 종류: 공격(피해), 막기(호신강기: 이번 턴 피해를 막음), 신법(뽑기·내공), 심법(전투 내내 효과).
- 저주 카드는 「내상」(뽑으면 체력 −1), 「주화입마」(내공 −1)이다.

### 3.2 결 연계 (이 게임만의 규칙)

- 모든 초식 카드에는 결이 하나 있다: **강(剛)** 묵직함, **유(柔)** 흘림, **쾌(快)** 빠름.
- 비급 한 권 = 결 순서 하나 + 비기 하나. 예:
  - 「삼재검법」: 쾌 → 쾌 → 강 / 비기: 마지막 초식 피해 ×3
  - 「태극권」: 유 → 강 → 유 / 비기: 받은 피해만큼 되돌려 준다
  - 「낙엽비도」: 쾌 × 4 / 비기: 적 전체에 비도 4개
- 비급 순서를 한 칸 맞출 때마다 **연계**가 1 오른다. 피해 = 초식 위력 × (1 + 연계 × 0.5).
- 순서를 끝까지 이으면 비기가 터지고 연계는 다시 0이 된다. 틀린 결을 내면 연계가 0이 된다.
- 비급은 최대 3권까지 들 수 있다(객잔에서 더 늘릴 수 있음). 여러 비급이 같은 카드를 동시에 셀 수 있다.
- 손패에서 카드를 고르면 어떤 비급이 몇 칸 차는지 바로 보인다.

### 3.3 문파 (시작 덱과 고유 규칙)

| 문파 | 결 비율 | 고유 규칙 |
|---|---|---|
| 화산파 (시작) | 쾌 많음 | 같은 턴 세 번째 쾌 초식은 내공 0 |
| 소림사 | 강·유 | 호신강기가 턴이 지나도 절반 남는다 |
| 무당파 | 유 많음 | 유 초식이 다음 카드의 결을 바꿀 수 있다 |
| 개방 | 고르게 | 객잔 술이 두 배 효과. 술 취함 상태에서 결이 무작위 |
| 당문 | 쾌·독 | 독이 쌓인 적에게 연계 +1 |
| 마교 | 강 많음 | 체력을 써서 내공을 얻는다 |

- 처음에는 화산파만 할 수 있다. 문파는 완주나 과제로 해금한다(5장).

## 4. 객잔 (이 게임의 쉬는 곳·가게)

객잔 칸에 들어가면 은자로 다음 중 몇 개를 한다.

| 하는 일 | 내용 |
|---|---|
| 하룻밤 묵기 | 체력 30% 회복 |
| 운기조식 | 카드 하나 강화(묵기와 둘 중 하나만) |
| 점소이에게 소문 듣기 | 다음 갈림길 칸 몇 개의 내용이 미리 보인다 |
| 술·음식 사기 | 소모품(최대 3개). 예: 「여아홍」 다음 전투 첫 턴 내공 +2, 「만두」 체력 회복 |
| 비급 사기·팔기 | 이번 막 비급 3권 중 고르기 |
| 협객 고용 | 동료 1명(2칸). 턴마다 정해진 결의 카드를 하나 손패에 넣어 준다 |
| 카드 버리기 | 덱에서 카드 하나 빼기 |

- **정파·사파 명성:** 기연과 객잔 이벤트의 선택이 명성 저울을 움직인다. 정파 쪽이면 객잔 값이 싸지고 정파 비급이 많이 나온다. 사파 쪽이면 값은 비싸지만 강한 사파 비급과 암기가 나온다.

---

## 5. 막 보스 (장문인)

출시 9명. 막마다 2~3명 중 하나가 나온다. 모두 규칙 하나를 깬다.

| 보스 | 규칙 |
|---|---|
| 아미 장문인 | 같은 결을 두 번 연달아 내면 막힌다 |
| 점창 장문인 | 턴마다 내 손패 한 장의 결을 바꾼다 |
| 소림 방장 | 호신강기가 높을수록 반격 |
| 무당 장문인 | 내 연계를 빼앗아 자기 비기로 쓴다 |
| 마교 교주 | 체력 절반에서 두 번째 모습. 비급 하나를 봉인한다 |

## 6. 오래 하기 (전체 플레이 5시간 이상)

| 요소 | 내용 | 대략 시간 |
|---|---|---|
| 첫 완주 | 화산파로 3막 완주. 보통 4~7번 시도 | 4~6시간 |
| 문파 6개 | 시작 덱·고유 규칙이 달라 빌드가 바뀐다 | 문파마다 1~2시간 |
| 무림 비록 | 카드·비급·적·기연 도감. "연계 8 이상 한 번에 잇기" 같은 과제로 새 카드·비급이 풀린다 | 15시간 이상 |
| 마두 단계 1~15 | 문파마다 완주하면 하나씩. 적 강화, 객잔 값 상승, 저주 시작 등이 누적된다 | 30시간 이상 |
| 끝없는 강호 | 3막 뒤 계속. 이긴 싸움 수가 기록 | 끝없음 |
| 오늘의 강호 | 날마다 같은 seed와 문파, 기록 비교 | 매일 |

- 능력치 영구 강화는 없다. 해금은 **고를 거리**만 늘린다(공통 가이드 1장).
- 판이 끝나면 강호 일지 한 장: 가장 큰 비기, 핵심 비급, 누구에게 졌는지.

## 7. 화면

공통 가이드 2장의 크기 기준(1080p, 지시 문구 64px, 점수 120px, 버튼 160px)을 지킨다.

```
┌─────────────────────────────────────────────────────────────┐
│ [비급1 쾌·쾌·강 ●●○] [비급2 유·강·유 ○○○] [비급3]   은자 120   │
│                                                             │
│   협객(나) 체력 62/80                 낭인 체력 40  의도: ⚔ 12  │
│   호신강기 8                           자객 체력 25  의도: 🛡     │
│                                                             │
│              연계 2   →  다음 카드 ×2.0                       │
│                                                             │
│  [쾌][쾌][강][유][신법]   내공 ●●●            [ 턴 끝 ]        │
└─────────────────────────────────────────────────────────────┘
```

- 비급 막대는 맞춘 칸만큼 빛나고, 손패 카드를 들면 몇 칸이 더 찰지 미리 보인다.
- 비기가 터지면 화면이 잠깐 멈추고 먹선이 화면을 가르고, 비기 이름이 붓글씨처럼 크게 쓰인다.
- 실패: 협객이 무릎을 꿇고 화면이 먹빛으로 번진다.

### 7.1 처음 할 때 안내 (`Coach`)

1. 카드를 끌어 적에게 내기(구멍: 손패, 적) → 내면 다음
2. 적 의도 보기(구멍: 의도 표시) → 누르면 다음
3. 비급 막대 보기: 「쾌」 카드를 내서 한 칸 채우기(구멍: 비급 1) → 채우면 다음
4. 비급 끝까지 이어 비기 터뜨리기 → 터지면 다음
5. 첫 객잔: 「하룻밤 묵기」와 「운기조식」 중 하나 고르기 → 고르면 다음

## 8. 구조

[`games/rooster/docs/architecture.md`](../../rooster/docs/architecture.md)와 같은 규칙(Godot 4.7.x, GDScript, gdUnit4, 웹 미리보기)을 따른다.

```
Run (순수 로직, RefCounted, seed 결정론)
  ├─ ActMap.roll(rng) → 갈림길 15칸 × 3막
  ├─ Battle: Fighter(나·적), Intent, Deck(뽑기·버리기·소멸)
  │    Battle.play(card, target) / end_turn() → BattleLog(발동 순서 기록)
  ├─ Chain: 비급 순서 맞추기, 연계 배수, 비기 발동
  ├─ Hook: 비급·심법·문파·보스·협객이 같은 발동 지점에 붙는다
  │    on_turn_start / on_play / on_chain_step / on_secret_art / on_damage ...
  ├─ Inn: 묵기·운기조식·소문·소모품·비급·협객
  └─ Reward.roll(rng) → 카드 3장, 비급, 은자
화면(Control 씬)은 BattleLog를 받아 차례대로 연출만 한다.
```

- 적 AI는 의도 목록을 순서·확률로 고르는 데이터(`.tres`)다.
- `tools/sim.gd`: 탐욕 봇이 같은 seed로 런을 돌려 막별 생존율, 비급별 승률, 평균 연계를 출력한다.

## 9. MVP 범위

### 9.1 목표
웹에서 화산파로 3막 런 하나를 끝까지 할 수 있고, 순서를 맞춰 비기를 잇는 게 재미있는지 확인한다(3단계 끝).

### 9.2 콘텐츠 수량 (MVP → 출시)
- 문파 1 → 6, 카드 70 → 180, 비급 30 → 70, 일반 적 15 → 30, 강적 6 → 12, 장문인 3 → 9, 기연 20 → 50, 소모품 10 → 20, 협객 6 → 12

### 9.3 MVP에서 뺄 것
- 정파·사파 명성(4단계), 협객 고용(4단계)
- 온라인 순위표, 모바일 빌드

## 10. 위험 요소

| 위험 | 대응 |
|---|---|
| Slay the Spire를 그대로 베낀 느낌 | 카드를 내는 순서가 핵심인 결 연계와 비급을 앞에 세운다. 객잔·문파·정사 명성으로 무협 소재를 살린다 |
| 손패에 결이 안 맞아 연계가 운 | 신법 카드로 결 바꾸기·뽑기를 넉넉히 주고, 비급 순서는 3~4칸으로 짧게 한다 |
| 한 비급 독주 | 봇 2000판으로 비급별 승률을 보고 조정한다 |
| 무협 용어가 어렵다 | 결은 색과 모양(강 ■ 붉음, 유 ● 푸름, 쾌 ▲ 노랑)으로 먼저 보이고, 용어는 툴팁으로만 |
