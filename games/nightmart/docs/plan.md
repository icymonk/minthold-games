# 개발 단계 계획

기획: `docs/design.md`

각 항목은 PR 하나 단위다. 위에서부터 차례로 진행한다.

## 0단계 — 기반
- [x] 0-1 Godot 4.7 프로젝트, 화면 전환 뼈대, gdUnit4, CI(`nightmart.yml` → 공용 `godot.yml`), 웹 미리보기 `minthold-nightmart`
- [x] 0-2 Kenney CC0 그림(상품 굽기·카드·UI)과 효과음, `Coach` 단계별 안내 뼈대

## 1단계 — 규칙 엔진 (화면 없이 테스트로 검증)
- [x] 1-1 상품 카드 52장, 조합 10종 판정(`Combo`), 매출 × 만족 계산, 테스트
- [x] 1-2 `Shift`(손님 한 명): 손패 8장, 계산 4번·바꾸기 3번, 목표 매출, 꿀팁 발동 순서(`Hook`), 테스트
- [x] 1-3 `Run`(8일 밤): 손님 3명/밤, 돈·이자, 발주 목록 생성, seed 결정론, 헤드리스 봇 `tools/sim.gd`

## 2단계 — 한 손님 (재미 검증 1: "조합 맞추기가 재밌나")
- [ ] 2-1 계산대 화면: 손패·고르기·조합 미리 보기, 계산 연출(상품 하나씩 띵 → 매출 × 만족 폭발)
- [ ] 2-2 밤 지도(손님 3명 미리 보기·건너뛰기 보상), 발주 화면, 영업 끝 화면, 안내 1~5단계

## 3단계 — 한 런 (재미 검증 2: "빌드가 생기나")
- [ ] 3-1 알바 꿀팁 40종, 전단지 12종, 조합 강화 택배 10종
- [ ] 3-2 진상 손님 12종, 유통기한·폐기, 밤 날씨 6종
- [ ] 3-3 저장(밤 사이 이어 하기), 기록, 해금 장부

## 4단계 — 오래 하기 (재미 검증 3: "5시간 뒤에도 한 판 더 하고 싶나")
- [ ] 4-1 점장 8명(시작 덱), 영업 등급 8단계, 매장 확장 16종
- [ ] 4-2 꿀팁 80종·진상 20종으로 확장, 무한 영업, 오늘의 영업(일일 seed)
- [ ] 4-3 밸런스: 봇 2000판으로 밤별 목표 매출·가격 조정, 첫 완주까지 시간 측정
