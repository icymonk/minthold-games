# 심야 편의점 (Night Mart) 게임 기획서 v1

> **한 줄 소개:** 새벽 편의점 계산대에서 상품 카드로 세트를 맞춰 매출을 터뜨린다. 알바 꿀팁이 쌓일수록 삑 소리 한 번에 숫자가 폭발한다.
> **키워드:** 조합 덱빌딩 · 매출 × 만족 · 규칙을 비트는 꿀팁 · 진상 손님 · 유통기한 · 한 판 더

공통 기준(로그라이트 구조, 콘솔식 큰 화면, 단계별 안내)은 [`docs/game-guide.md`](../../../docs/game-guide.md)를 따른다. 이 문서는 이 게임에서 정하는 것만 적는다.

---

## 1. 개요

### 1.1 콘셉트

야간 알바 첫날. 점장은 "8일만 버티면 정직원"이라는 쪽지만 남기고 사라졌다. 새벽 손님은 하나같이 이상하고, 매출 목표는 밤마다 오른다. 내가 가진 건 진열대의 상품과, 선배 알바들이 남긴 **꿀팁 메모**뿐이다.

### 1.2 기본 사양

| 항목 | 방향 |
|---|---|
| 장르 | 1인 조합 덱빌딩 로그라이트. 한 판(런) 30~40분 |
| 전체 플레이 | 첫 완주까지 3~5시간, 해금 전부 12시간 이상, 그 뒤 영업 등급·무한 영업 |
| 플랫폼 | PC / Steam(Steam Deck), 웹 미리보기. 나중에 모바일 |
| 그래픽 | 2D 계산대 정면. Kenney CC0 Food Kit 3D 상품을 같은 각도·조명으로 2D로 굽고(8.2), 카드 틀은 코드로 그린다 |
| 조작 | 마우스·터치·패드: 카드 고르기 → 「계산」 또는 「바꾸기」 |
| 언어 | 한국어, 영어 |

### 1.3 핵심 재미

1. **조합 맞추기:** 손패 8장에서 최대 5장을 골라 1+1, 같은 코너, 세트 메뉴 같은 조합을 만든다. 버릴지 지킬지가 매 순간 고민이다.
2. **빌드:** 꿀팁 5칸이 조합 규칙을 비튼다. "음료가 3장 이상이면 만족 ×3" 하나가 런의 방향을 정한다.
3. **점수 폭발:** 상품이 하나씩 "삑" 찍히며 매출이 오르고, 마지막에 만족이 곱해지며 영수증이 길게 뽑혀 나온다.
4. **진상 손님:** 밤의 마지막 손님은 규칙 하나를 깬다. 내 빌드가 그 손님을 버틸 수 있는지가 시험이다.

### 1.4 비슷한 게임과 차별점

| 게임 | 공통점 | 이 게임의 차이 |
|---|---|---|
| Balatro | 칩 × 배수, 조커, 블라인드 3단계 | 포커 대신 **편의점 조합**(한 끼 세트, 같은 코너). 상품에 **유통기한**이 있어 덱이 썩는다. 밤 **날씨**가 가격을 흔든다 |
| Slay the Spire | 덱 키우기, 보스 | 전투가 없다. 한 번의 계산으로 점수를 만든다 |
| 편의점 경영 시뮬레이터류 | 소재 | 운영이 아니라 계산대 한 판의 조합 퍼즐 |

Steam 상점 검색(2026-11)에서 "Night Mart", "Midnight Mart"로 나오는 게임은 없었다.

## 2. 한 판의 흐름

```
런 = 8일 밤
밤 = 손님 3명: 일반 손님 → 단골 → 진상 손님(보스)
손님 1명 = 목표 매출 + 계산 4번 + 바꾸기 3번
손님 사이 = 발주(가게)
```

- 손님마다 덱(진열대)을 섞어 8장을 뽑는다. **계산**은 고른 카드로 점수를 내고, **바꾸기**는 고른 카드를 버리고 새로 뽑는다.
- 계산 4번 안에 목표 매출을 넘기면 손님을 보낸다. 받는 돈(초기값, 4-3에서 조정):
  - 손님 값: 일반 3천, 단골 4천, 진상 5천
  - 남은 계산 1번당 1천
  - 목표를 한 배 넘길 때마다 1천(최대 3천)
  - 이자(6장)는 받기 직전 가진 돈으로 센다. 시작 돈은 4천.
- 일반 손님과 단골은 **건너뛸 수 있다.** 건너뛰면 돈을 못 받는 대신 "건너뛰기 보상"을 받는다. 보상은 밤 지도에 미리 보인다: 공짜 택배, 다음 발주 반값(한 번), 새로 고침 공짜(한 번), 공짜 전단지(한 장).
- 어느 손님이든 목표를 못 넘기면 런이 끝난다(건너뛰기가 그 대신이다). 8일째 진상 손님(본사 감사)을 넘기면 정직원, 완주다. 그 뒤 **무한 영업**으로 계속할 수 있다.

### 2.1 목표 매출 (초기값, 4-3에서 조정)

| 밤 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 일반 손님 | 3천 | 8천 | 2만 | 5만 | 11만 | 20만 | 35만 | 50만 |

단골은 ×1.5, 진상 손님은 ×2. 영업 등급이 오르면 곡선이 가팔라진다.

## 3. 상품 카드와 조합

### 3.1 상품 카드 (기본 덱 52장)

- **코너 4개:** 식사(라면·도시락·김밥), 간식(과자·아이스크림), 음료(커피·우유), 생활(수저·봉투·소스·주방용품). 트럼프의 무늬 역할이다.
- **가격 1~13:** 1은 껌, 13은 와인처럼 비쌀수록 높다. 트럼프의 숫자 역할이며, 매출에 가격 × 100원이 더해진다.
- **꼬리표(강화):** 전단지로 붙인다. 할인(매출 +), 행사(만족 +), 냉장(만족 ×1.5, 대신 유통기한), PB(어느 코너로도 셈), 금박(손에 남아 있으면 돈).

### 3.2 조합 10종

| 조합 | 조건 | 기본 매출 | 기본 만족 |
|---|---|---|---|
| 낱개 | 가장 비싼 1장 | 500 | 1 |
| 1+1 | 같은 가격 2장 | 1,000 | 2 |
| 2+2 | 1+1 두 쌍 | 2,000 | 2 |
| **한 끼 세트** | 식사·간식·음료 각 1장 이상 | 2,500 | 3 |
| 3개 묶음 | 같은 가격 3장 | 3,000 | 3 |
| 진열 줄 | 가격이 이어진 5장 | 3,000 | 4 |
| 같은 코너 | 같은 코너 5장 | 3,500 | 4 |
| 세트 메뉴 | 3개 묶음 + 1+1 | 4,000 | 4 |
| 박스째 | 같은 가격 4장 | 6,000 | 7 |
| 완벽 진열 | 같은 코너로 이어진 5장 | 10,000 | 8 |

- 점수 = (조합 매출 + 낸 카드 가격 합 × 100 + 꼬리표·꿀팁) × (조합 만족 + 꼬리표·꿀팁)
- **택배**(소모품)로 조합을 강화하면 그 조합의 기본 매출·만족이 오른다(레벨). 레벨 1당 기본 매출의 절반(100원 단위)과 만족 +1.
- 꼬리표 초기값: 할인 매출 +500, 행사 만족 +2, 냉장 만족 ×1.5. 폐기 카드는 조합·가격 합에서 빠진다.
- 여러 조합이 되면 표에서 아래쪽(더 센) 것 하나만 인정한다. 진열 줄은 이어진 가격 5개, 같은 코너는 같은 코너 5장이 있어야 한다(꿀팁으로 4로 줄일 수 있다).
- **발동 순서:** 조합 기본값 → 낸 카드 왼쪽부터(가격 → 꼬리표 → 카드에 반응하는 꿀팁) → 꿀팁 왼쪽부터. 더하기와 곱하기가 이 순서대로 바로 적용되므로 곱하는 꿀팁은 오른쪽에 둘수록 세다.

### 3.3 유통기한과 폐기 (이 게임만의 규칙)

- 냉장 꼬리표 상품(3밤)과 일부 상품(도시락·우유, 5밤)에는 유통기한 도장(밤 수)이 있다. 밤이 지날 때마다 1씩 준다.
- 0이 되면 **폐기 카드**로 바뀐다. 폐기 카드는 조합에 안 들어가고 손패만 차지한다.
- 폐기를 점수로 바꾸는 꿀팁("폐기 도시락 야식": 폐기 1장당 만족 +2)이 있어서, 폐기를 쌓는 빌드도 된다.

### 3.4 밤 날씨 (밤마다 하나, 미리 보임)

| 날씨 | 효과 |
|---|---|
| 비 | 생활 코너 가격 ×2 |
| 한파 | 음료 만족 +1, 간식 가격 절반 |
| 월드컵 | 음료와 간식을 함께 내면 만족 ×2, 손님 목표 ×1.2 |
| 시험 기간 | 낱개·1+1 만족 +3 |
| 정전 | 처음 받는 카드 2장이 뒷면 |
| 월급날 | 손님 값 ×2 (첫 밤은 늘 맑음) |

## 4. 알바 꿀팁 (Balatro의 조커)

꿀팁 메모는 계산대 위 5칸에 붙인다. 왼쪽부터 차례로 발동하므로 **순서**도 빌드다.

| 꿀팁 | 효과 |
|---|---|
| 컵라면엔 삼각김밥 | 식사 카드 2장 이상 계산하면 만족 +4 |
| 1+1 장인 | 1+1을 계산할 때마다 이 메모의 만족 +1 (계속 쌓임) |
| 냉장고 정리왕 | 냉장 상품 만족 ×1.5 대신 ×2 |
| 폐기 도시락 야식 | 손패의 폐기 1장당 만족 +2 |
| 진열 줄 집착 | 진열 줄은 4장으로도 된다 |
| 사장님 조카 | 계산할 때마다 돈 +2, 바꾸기 1번 줄어듦 |
| 새벽 3시 | 그 손님의 마지막 계산 점수 ×3 |
| 같은 코너 고집 | 같은 코너 조건이 4장으로 줄어듦 |
| 포인트 적립 | 계산한 카드 1장당 이 메모 매출 +50 (계속 쌓임) |
| 퇴근 5분 전 | 남은 계산이 1번이면 만족 ×2 |

- MVP 40종, 출시 80종. 등급은 흔함·보통·귀함·전설 4단계이고 전설은 해금해야 나온다.
- 꿀팁 판매: 산 값의 절반을 돌려받는다.

### 4.1 소모품 (2칸)

- **전단지 12종:** 카드에 꼬리표를 붙이거나, 가격을 바꾸거나, 카드를 복사·삭제한다(Balatro의 타로).
- **택배 10종:** 조합 하나를 1레벨 올린다(Balatro의 행성).

## 5. 진상 손님 (보스)

밤의 세 번째 손님. 지도에서 미리 보인다.

| 손님 | 규칙 |
|---|---|
| 카드만 내미는 손님 | 생활 코너 카드 매출 0 |
| 1+1 따지는 손님 | 1+1·2+2는 0점 |
| 술 취한 손님 | 손패 -1장 |
| 봉투 달라는 손님 | 계산할 때마다 돈 −500원 |
| 바코드 안 찍힘 | 첫 계산은 점수 0 |
| 다이어트 중 | 간식 카드가 뒷면으로 나옴 |
| 거스름돈 동전으로 | 바꾸기 0번 |
| 급한 손님 | 계산 −1번 |
| 한 아름 손님 | 한 번에 3장까지만 계산 |
| 같은 거 또? | 이미 계산한 조합은 0점 |
| 쿠폰 안 받는 손님 | 할인·행사 꼬리표 효과 없음 |
| 본사 감사(8일째) | 꿀팁 하나가 무작위로 꺼짐, 목표 ×3 |

MVP 12종, 출시 20종.

## 6. 발주 (가게)

- 손님을 보낼 때마다 열린다. 꿀팁 2개, 소모품 2개, 상품 팩 2개, 매장 확장 1개가 나온다.
- 값(초기값): 꿀팁 5천, 소모품 3천, 상품 팩 4천, 매장 확장 1만. 꿀팁은 5칸, 소모품은 2칸이 차면 못 산다.
- 새로 고침 5천 원(누를 때마다 +1천 원).
- 돈 5천 원마다 이자 1천 원(최대 5천 원).
- **상품 팩:** 상품 카드 3장 중 1장을 덱에 넣는다(꼬리표 붙은 것이 섞여 나옴). 전단지 팩, 택배 팩도 3장 중 1장 고르기다.
- **매장 확장(영구, 그 런 동안):** 계산대 하나 더(계산 +1), 창고(손패 +1), 할인 계약(발주 25% 할인), 냉장 쇼케이스(냉장 유통기한 +2) 등. MVP 8종, 출시 16종.

## 7. 오래 하기 (전체 플레이 5시간 이상)

| 요소 | 내용 | 대략 시간 |
|---|---|---|
| 첫 완주 | 기본 점장으로 8일 밤 완주. 보통 3~6번 시도 | 3~5시간 |
| 점장 8명 | 시작 덱과 규칙이 다르다. 예: 「도시락 점장」(식사 카드 많고 유통기한 짧음), 「폐기왕」(폐기 카드로 시작), 「PB 점장」(코너가 없는 덱) | 점장마다 1~2시간 |
| 해금 장부 | 꿀팁·전단지·확장·진상 손님 도감. "같은 코너로 5만 원 넘기기" 같은 조건을 채우면 새 꿀팁이 풀린다 | 12시간 이상 |
| 영업 등급 1~8 | 점장마다 완주할 때마다 한 단계 오른다. 목표 상승, 진상 손님 추가 규칙, 발주 가격 상승 등이 누적된다 | 20시간 이상 |
| 무한 영업 | 9일째부터 목표가 계속 오른다. 최고 기록 | 끝없음 |
| 오늘의 영업 | 날마다 같은 seed, 기록 비교 | 매일 |

- 능력치 영구 강화는 없다. 해금은 **고를 거리**만 늘린다(공통 가이드 1장).
- 3-3 해금 장부(MVP): 과제 10개가 꿀팁 10종(귀함 7·보통 3)을 하나씩 푼다. 풀리기 전에는 발주에 안 나온다. 봇 시뮬레이터는 전부 풀린 채로 돈다.

| 과제 | 풀리는 꿀팁 |
|---|---|
| 3일째 밤까지 가기 | 줄 세우기 |
| 진상 손님 3명 보내기 | 코너 사수 |
| 한 번에 5만 점 넘기기 | 짝꿍 |
| 같은 코너 3번 계산 | 편의점 한 바퀴 |
| 한 끼 세트 5번 계산 | 삼총사 |
| 돈 2만 원 모으기 | 퇴근 5분 전 |
| 꿀팁 5칸 채우기 | 경력직 |
| 안 건너뛰고 5일째 | 고급 진열 |
| 날씨 7가지 다 보기 | 루틴 |
| 8일 완주하기 | 같은 가격 셋 |

- 장부에는 기록(판 수, 완주 수, 최고 밤, 최고 계산)과 도감(산 꿀팁, 쓴 전단지, 만난 진상 손님, 겪은 날씨의 종류 수)도 적는다.
- 저장: 런은 seed와 행동 기록(손패 index)만 저장한다. 행동마다 저장하고, 이어 하기는 같은 seed로 행동을 다시 돌려 런을 만든다. 런이 끝나면 저장을 지우고 장부에 적는다.
- 판이 끝나면 영수증 화면: 가장 큰 계산, 핵심 꿀팁, 무엇 때문에 졌는지(진상 손님 규칙) 한 장면으로 보여 준다.

## 8. 화면

공통 가이드 2장의 크기 기준(1080p, 지시 문구 64px, 점수 120px, 버튼 160px)을 지킨다.

```
┌─────────────────────────────────────────────────────────────┐
│ [꿀팁1][꿀팁2][꿀팁3][꿀팁4][꿀팁5]          [전단지][택배]   │
│                                                             │
│  손님 그림 + 목표 50,000      [ 매출 3,500 ] × [ 만족 4 ]      │
│  계산 ●●●○  바꾸기 ●●○                   돈 12,000원          │
│                                                             │
│        ┌──계산대(고른 카드가 올라감)──┐   "같은 코너!"         │
│                                                             │
│  [상품][상품][상품][상품][상품][상품][상품][상품]   손패 8장     │
│        [ ▶ 계산 ]                    [ ↻ 바꾸기 ]            │
└─────────────────────────────────────────────────────────────┘
```

- 카드를 고르면 그 조합 이름과 예상 점수가 바로 뜬다.
- 계산 연출: 카드가 하나씩 스캐너를 지나며 "삑"과 함께 매출 숫자가 튀어 오르고, 꿀팁이 차례로 흔들리며 발동한다. 마지막에 매출 × 만족이 곱해지면 숫자가 커지며 터지고 영수증이 나온다.
- 실패: 손님이 화내며 나가고, 형광등이 깜빡이고, 화면이 흔들린다.

### 8.1 처음 할 때 안내 (`Coach`)

1. 카드를 눌러 고르기(구멍: 손패) → 실제로 2장 고르면 다음
2. 「1+1」 이름과 예상 점수 보기(구멍: 조합 표시) → 누르면 다음
3. 「계산」 누르기(구멍: 계산 버튼) → 계산하면 다음
4. 「바꾸기」로 안 쓸 카드 버리기 → 바꾸면 다음
5. 첫 발주 화면에 처음 들어갈 때: 꿀팁 하나 사기 → 사면 다음

### 8.2 아트 방향 (공통 가이드 4장)

- **분위기:** 새벽 3시, 형광등 아래 조용한 계산대. 어두운 남색 매장에 흰 카드와 네온 초록 강조가 떠 보인다.
- **참고:** Balatro(카드가 튀고 숫자가 터지는 손맛), 「Unpacking」(물건 하나하나가 귀여운 소품).
- **색상표:** 배경 `NIGHT #121626`·`NIGHT_DEEP #0A0D18`, 본문 `FLUORESCENT #EAF6FF`, 강조 `NEON #3DDC97`, 돈 `PRICE #FFD23F`, 위험 `ANGRY #FF4D6D`. 코너 띠 색은 식사 주황·간식 분홍·음료 하늘·생활 보라.
- **그림:** 상품은 모두 Kenney Food Kit(CC0) 3D 모델을 위 28도·옆 30도 정사영, 같은 조명으로 굽는다(`tools/art_bake`). 아이콘은 Kenney Game Icons, 효과음은 Kenney Casino·Interface Audio.
- **깊이:** 배경은 위가 밝은 원형 그라데이션과 가끔 깜빡이는 형광등. 카드와 버튼에는 그림자, 고른 카드는 커지고 네온 테두리.

## 9. 구조

[`games/rooster/docs/architecture.md`](../../rooster/docs/architecture.md)와 같은 규칙(Godot 4.7.x, GDScript, gdUnit4, 웹 미리보기)을 따른다.

```
Run (순수 로직, RefCounted, seed 결정론)
  ├─ Night × 8 → Shift × 3 (손님 한 명)
  │    Shift.play(cards) / discard(cards) → ScoreLog(발동 순서 기록)
  ├─ Combo.evaluate(cards, mods) → { kind, scored_cards }
  ├─ Hook: 꿀팁·꼬리표·날씨·진상 손님이 같은 발동 지점에 붙는다
  │    on_score_card / on_combo / on_hand_end / on_discard / on_night_end ...
  └─ Shop.roll(rng) → 발주 목록
화면(Control 씬)은 ScoreLog를 받아 차례대로 연출만 한다.
```

- 점수 계산은 `ScoreLog` 한 줄씩(어느 카드·꿀팁이 매출·만족을 얼마나 바꿨는지)으로 남긴다. 테스트, 연출, "무엇 때문에 졌나" 화면이 같은 기록을 쓴다.
- 꿀팁·진상 손님·날씨는 `.tres` 데이터 + 효과 스크립트 하나씩.
- `tools/sim.gd`: 탐욕 봇이 같은 seed로 런을 돌려 밤별 통과율, 조합별 사용 비율, 꿀팁별 승률을 출력한다.
