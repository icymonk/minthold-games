# 심야 편의점 (`nightmart`)

**심야 편의점 (Night Mart)** — 새벽 편의점 계산대에서 상품 카드로 세트를 맞춰 매출을 터뜨리는 조합 덱빌딩 로그라이트 (Godot 4, Steam).

- 웹 미리보기: https://minthold-nightmart.web.app (`develop` 머지 시 자동 배포)
- 기획서: [docs/design.md](docs/design.md)
- 개발 단계: [docs/plan.md](docs/plan.md)
- 그림·효과음: [Kenney](https://kenney.nl) CC0 팩([라이선스](assets/art/kenney/LICENSE-Kenney.txt)). 다시 굽기: `bash tools/art_bake/bake.sh`(화면 필요)

공통 기준은 [`docs/game-guide.md`](../../docs/game-guide.md), 구조와 개발 환경은 [`games/rooster/docs/architecture.md`](../rooster/docs/architecture.md)를 따른다(Godot 4.7.x, gdUnit4, 규칙 로직과 화면 분리).
