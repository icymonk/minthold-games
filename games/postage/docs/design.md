# 우표 붙이는 우체국 (Postage Paid) 게임 기획서 v1

> **한 줄 소개:** 동네 우체국 창구 직원이 되어, 손에 든 우표로 소포마다 요구하는 요금 조건을 맞춰 발송하고, 다른 창구보다 먼저 실적 12점을 채우는 카드 조합 게임.
> **키워드:** 2D · 카드 조합 · 한 턴에 행동 3번 · 엔진 빌딩(창구 설비) · AI 동료와 대결 · 일상 소재

---

## 1. 개요

### 1.1 콘셉트

오후 4시, 우체국 마감 2시간 전이다. 손님들이 소포를 들고 줄을 서 있고, 창구 직원 여럿이 같은 우표 진열대에서 우표를 가져다 쓴다.

소포마다 붙여야 하는 요금 조건이 다르다. "합계 10원", "같은 우표 3장", "번호가 이어지는 우표 3장" 같은 식이다. 손에 든 우표를 조합해서 조건을 정확히 맞추면 발송 완료. 실적 점수를 받고, 어떤 소포는 창구에 계속 남는 혜택(설비·단골 손님)을 준다.

실력이 드러나는 곳은 **어떤 소포를 창구에 올려 둘지, 지금 우표를 모을지 발송할지 고르는 판단**이다.

이 게임의 규칙 뼈대는 보드게임 「몰타르의 포탈(Die Portale von Molthar, AMIGO 2015)」을 참고했다(1.4). 카드 이름·문구·조건 목록·그림은 모두 새로 만든다.

### 1.2 기본 사양

| 항목 | 방향 |
|---|---|
| 장르 | 턴제 카드 조합 게임, 싱글(AI 동료 1~3명과 대결) |
| 플랫폼 | PC / Steam (Steam Deck 대응 목표), 개발 중에는 웹 미리보기. 나중에 모바일 |
| 그래픽 | 2D 플랫 일러스트, 우체국 창구를 위에서 내려다본 책상 한 화면 |
| 조작 | 마우스 클릭·드래그(우표를 소포에 끌어다 붙임), 컨트롤러 대응 |
| 1판 시간 | 약 15~20분 (AI 3명 기준) |
| 언어 | 한국어, 영어 (처음부터 번역 테이블로 관리) |

### 1.3 핵심 재미

1. **조합 맞추기:** 손에 든 우표 5장으로 어느 소포를 맞출 수 있는지 계속 계산한다. "6 하나만 더 있으면 두 소포를 다 보낸다."
2. **행동 3번의 배분:** 우표를 모을지, 진열대를 새로 고칠지, 소포를 받을지, 발송할지. 매 턴 행동은 3번뿐이다.
3. **창구가 강해지는 맛:** 발송한 소포 중 일부는 영구 혜택을 남긴다(저울: 1을 8로 씀, 단골: 행동 +1 등). 판이 진행될수록 내 창구가 굴러간다.
4. **눈치 싸움:** 진열대 우표와 대기 소포는 모두가 같이 쓴다. 상대가 노리는 우표를 먼저 가져가거나, 반송 소포를 가로챈다.

### 1.4 비슷한 게임과 차별점

| 게임 | 공통점 | 이 게임의 차이 |
|---|---|---|
| 몰타르의 포탈 (보드게임) | 규칙 뼈대(행동 3번, 숫자 카드 조합으로 캐릭터 발동, 슬롯 2칸, 12점) | 판타지 대신 **우체국 일상 소재**, 우표를 소포에 붙이는 연출, **대기 줄 보너스**(4.4), **마감 시계**(2), 디지털 AI 대결 |
| Splendor | 카드를 사서 엔진을 키우는 구조 | 자원 토큰이 아니라 **숫자 조합(합계·짝·연속)** 퍼즐 |
| Balatro | 포커식 조합의 쾌감 | 혼자 점수 내기가 아니라 같은 시장을 나눠 쓰는 대결, 덱 빌딩 없음 |
| Post Office Simulator 등 | 우체국 소재 | 시뮬레이션이 아니라 카드 조합 게임 |

Steam에서 "postage", "post office", "stamp"로 검색했을 때 같은 이름이나 우표 조합 카드 게임은 찾지 못했다. 「Combo Postage」는 상자를 쌓는 액션 플랫포머라 겹치지 않는다(2026-11 Steam 상점 검색 기준).

## 2. 한 판의 흐름

```
[준비] 우표 진열대 4장 + 대기 소포 2개 공개, 각자 창구(빈 칸 2개)
[턴]   행동 3번 → 우표첩 5장 넘으면 버림 → 다음 사람
…
[마감] 누군가 실적 12점 이상 → 그 바퀴 끝까지 진행 → 최고 점수 승리
       또는 마감 시계(6시)가 다 되면 그 바퀴 끝까지 진행
```

- **실적(점수)**은 발송한 소포에서만 얻는다. 동점이면 동전을 더 많이 가진 사람이 이긴다.
- **마감 시계:** 우표 더미를 한 번 다 쓸 때마다 시계가 30분 흐른다(4시 → 6시, 4번). 판이 끝없이 늘어지는 것을 막는다. 원작에는 없는 장치다.
- 시작 플레이어 다음 사람부터 차례로 우표 1장을 더 받고 시작한다(후순위 보정).

## 3. 카드

### 3.1 우표 카드 (56장)

- 1원~8원, 값마다 7장.
- 우표 더미에서 **새 진열대를 뒤집다 "우편 행낭" 표시가 나오면** 대기 소포 2개를 모두 버리고 새로 2개를 깐다(준비 중에는 무시). 56장 중 6장에 표시.
- 우표첩(손) 한도 5장. 턴이 끝날 때만 검사한다.

### 3.2 소포 카드 (MVP 40장)

소포 카드 한 장에 적힌 것:

| 항목 | 설명 |
|---|---|
| 요금 조건 | 발송하려면 내야 하는 우표 조합 (3.3) |
| 실적 | 0~5점 |
| 동전 | 0~2개. 발송하면 소포 더미 맨 위 카드를 뒷면으로 받아 동전으로 쓴다 |
| 혜택 | 없음 / 1회(빨강) / 영구(파랑) (5장) |
| 선납 우표 | 일부 소포에 인쇄된 우표(값 또는 "아무 값"). 이 소포가 내 창구 옆에 발송돼 있으면, 이후 발송할 때마다 한 번 우표 1장으로 쳐 준다 |

### 3.3 요금 조건 (MVP 12종)

조건 문구와 구성은 원작과 다르게 새로 짠다.

| 이름 | 조건 | 난이도 |
|---|---|---|
| 일반 우편 | 같은 값 2장 | 쉬움 |
| 엽서 묶음 | 1원 3장 | 보통 |
| 정확한 요금 | 합계가 정확히 N원 (N = 9~15, 장수 자유) | 보통 |
| 소형 포장 | 3장, 합계 8원 이하 | 보통 |
| 대형 포장 | 2장, 합계 14원 이상 | 보통 |
| 등기 | 같은 값 3장 | 보통 |
| 짝수 묶음 | 짝수 값 3장 | 보통 |
| 홀수 묶음 | 홀수 값 3장 | 보통 |
| 국제 우편 | 두 쌍(같은 값 2장 + 같은 값 2장) | 어려움 |
| 번호 순 | 연속 값 3장 | 어려움 |
| 우표 수집가 | 연속 값 5장 | 아주 어려움 |
| 지정 요금 | 인쇄된 값 2~3장 그대로 (예: 4·6·8) | 어려움 |

## 4. 턴

### 4.1 행동 (아래 4개 중 3번, 같은 행동 반복 가능, 순서 자유)

1. **우표 받기:** 진열대 4장 중 1장 또는 더미 맨 위 1장을 우표첩에 넣는다. 진열대에서 가져가면 바로 더미에서 채운다.
2. **진열대 새로 고치기:** 진열대 4장을 모두 버리고 더미에서 4장을 새로 깐다.
3. **소포 접수:** 대기 소포 2개 중 하나 또는 소포 더미 맨 위 1장을 내 창구 칸에 올린다. 창구는 2칸. 꽉 찼으면 하나를 버리고 올린다.
4. **발송:** 창구에 있는 소포 하나의 요금 조건에 맞는 우표를 내고(버림), 그 소포를 창구 옆 "발송함"으로 옮긴다. 실적·동전·혜택을 받는다.

### 4.2 동전

- 우표 1장의 값을 +1 한다(8을 넘을 수 없음). 우표 1장에 동전 1개까지.
- 쓴 동전은 소포 버림 더미로 간다.
- 원작처럼 기본은 올리기만 되고, 내리기(−1)는 혜택 "거스름돈"이 있어야 한다.

### 4.3 반송 소포

- 소포 중 4장은 "반송" 표시가 있다. 내 창구에 올리면 **양옆 사람이 자기 턴에 먼저 발송해 가져갈 수 있다.** 내 턴이 다시 와야 나도 발송할 수 있다.
- 발송하면 실적 3점. 위험하지만 점수가 크다.

### 4.4 대기 줄 보너스 (원작과 다른 점)

- 대기 소포 2개 중 한 바퀴 동안 아무도 가져가지 않은 소포에는 "기다림" 표시를 1개 올린다(최대 2개).
- 그 소포를 발송하면 기다림 표시 1개당 실적 +1. 인기 없는 소포도 언젠가는 누가 가져가게 만든다.

## 5. 혜택

**1회(빨강):** 발송한 즉시 한 번 쓰고 끝.

| 이름 | 효과 |
|---|---|
| 속달 | 행동 3번을 바로 더 한다 |
| 점심 교대 | 다음 사람은 다음 턴에 행동 +1 |
| 분실물 | 상대 한 명의 우표첩을 보고 1장 가져온다 |
| 재사용 | 방금 낸 우표 1장을 우표첩으로 돌려받는다 |
| 민원 | 상대 창구 소포 하나를 버리게 한다 |

**영구(파랑):** 발송함에 있는 동안 계속.

| 이름 | 효과 | 쓰는 때 |
|---|---|---|
| 저울 | 1원 우표를 8원으로 쓸 수 있다 | 발송할 때 |
| 만능 소인 | 3원 우표를 아무 값으로 쓸 수 있다 | 발송할 때 |
| 거스름돈 | 동전으로 −1도 할 수 있다(1 아래로는 안 됨) | 발송할 때 |
| 동전 교환 | 2원 우표 1장을 버리고 동전 1개를 받는다 | 내 턴 아무 때 |
| 큰 우표첩 | 우표첩 한도 +1 | 항상 |
| 단골 손님 | 매 턴 행동 +1 | 항상 |
| 창구 정리 | 첫 행동 전에 내 창구 소포 1개와 대기 소포 1개를 맞바꾼다 | 턴 시작 |
| 소포 미리 보기 | 첫 행동 전에 소포 더미 맨 위를 본다 | 턴 시작 |
| 정리 정돈 | 마지막 행동 후, 턴당 한 번 우표첩을 모두 버리고 같은 장수를 받는다 | 턴 끝 |

## 6. AI 동료 (MVP 3명)

| 이름 | 성향 |
|---|---|
| 신입 민지 | 쉬움. 지금 당장 보낼 수 있는 소포만 노린다 |
| 계장 박 | 보통. 영구 혜택을 먼저 모아 엔진을 키운다 |
| 국장 최 | 어려움. 남이 노리는 우표를 끊고, 반송 소포를 노린다 |

- AI는 규칙 엔진의 "가능한 행동 목록"을 받아 점수를 매겨 고른다. 같은 시드면 같은 수를 둔다(테스트·재현용).
- AI의 우표첩은 보이지 않는다. 장수만 보인다.

## 7. 반복 플레이

- **근무 주간 (정식 출시):** 월~금 5판 연속. 이기면 다음 날 영구 혜택 하나를 시작 혜택으로 고른다. 금요일은 "명절 소포" 규칙(조건이 어려운 대신 실적 2배).
- **오늘의 우체국:** 날짜 시드로 모두 같은 카드 순서를 받아 점수를 겨룬다(정식 출시).
- **카드 해금:** 판을 끝낼 때마다 새 소포·혜택이 덱에 섞인다.

## 8. MVP 범위

### 8.1 목표

**AI 1~3명과 한 판을 끝까지 할 수 있는 프로토타입.** "조합 맞추는 게 재밌나", "행동 3번 배분이 고민되나"를 먼저 검증한다.

### 8.2 콘텐츠 수량

| 항목 | MVP | 정식 출시 목표 |
|---|---:|---:|
| 우표 | 56 | 56 |
| 소포 | 40 | 70 |
| 요금 조건 | 12 | 20 |
| 혜택 | 1회 5 + 영구 9 | 1회 10 + 영구 16 |
| AI 동료 | 3 | 6 |
| 모드 | 한 판 | 한 판 + 근무 주간 + 오늘의 우체국 |

### 8.3 반드시 구현할 것

1. 우표·소포 더미, 진열대, 버림 더미, 더미 다 쓰면 섞기
2. 행동 4종, 행동 3번, 우표첩 한도
3. 요금 조건 판정(동전·선납 우표·혜택 포함)과 "지금 보낼 수 있는 소포" 표시
4. 혜택 14종, 반송 소포, 대기 줄 보너스, 마감 시계
5. AI 3명, 시드 고정
6. 결과 화면(실적·동전), 다시 하기

### 8.4 MVP에서 뺄 것

근무 주간, 오늘의 우체국, 카드 해금, 온라인 대전, 모바일 빌드, 일러스트 본작업.

## 9. 위험 요소

|위험 | 문제 | 대응 |
|---|---|---|
| 원작과 너무 비슷함 | 규칙 뼈대가 같아 "테마만 바꾼 복제"로 보일 수 있다 | 카드 문구·조건·그림은 새로 만들고, 대기 줄 보너스·마감 시계·근무 주간처럼 원작에 없는 장치를 넣는다. 정식 출시 전에 규칙을 더 비틀지 다시 검토 |
| 계산 피로 | 조합을 매번 머릿속으로 찾기 귀찮다 | 보낼 수 있는 소포를 빛나게 표시하고, 우표를 끌어다 놓으면 남은 조건을 바로 보여 준다 |
| 운 | 원하는 우표가 안 나오면 할 게 없다 | 진열대 새로 고치기, 동전, 우표 더미 직접 받기로 길을 여러 개 둔다 |
| AI 턴이 지루함 | 상대 3명이 3번씩 행동하면 기다림이 길다 | AI 행동은 빠르게 재생(배속·건너뛰기), 중요한 행동(발송·가로채기)만 멈춰 보여 준다 |
| 싱글만으로 부족함 | 원작의 재미는 사람끼리의 눈치 싸움 | AI 성향을 뚜렷하게, 나중에 같은 화면 여러 명(핫시트) 검토 |

- "Postage paid"는 "요금 별납"이라는 우편 용어라 요금을 맞춰 내는 규칙과 바로 이어진다. Steam에서 같은 이름은 찾지 못했다(2026-11 기준).
- 다른 후보: 마감 2시간 전(Two Hours to Closing), 창구 3번(Window No. 3).
- 코드명은 `postage`(`games/postage/`, Firebase 사이트 `minthold-postage`).

## 11. 먼저 확정할 규칙

아래는 이 기획서의 **추천값**이다. 프로토타입에서 실제로 해 보고 숫자를 확정한다.

| 항목 | 추천 | 대안 |
|---|---|---|
| 목표 실적 | 12점 | AI 1명 대결은 10점 |

| 우표첩 한도 | 5장 | 6장 |
| 창구 칸 | 2칸 | 3칸(쉬움 모드) |
| 마감 시계 | 우표 더미 4번 소진 | 없음 |
| 동전 −1 | 혜택이 있어야 가능 | 처음부터 ±1 |

## 12. 아트 가이드 (프로토타입 기준)

- **방향:** 오래된 동네 우체국 창구 책상을 위에서 본 화면. 아래쪽에 내 우표첩과 창구 2칸, 위쪽에 진열대·대기 소포·AI 동료 창구.
- **색상표:** 책상 나무 `#A9744F`, 우체국 빨강 `#D9412E`, 크라프트지 소포 `#C9A27A`, 종이 크림 `#F5EEDC`, 잉크 남색 `#2B3A67`, 소인 검정 `#2A2A2A`, 동전 금색 `#E3B341`.
- **카드:** 우표는 톱니 테두리 정사각형, 값이 크게 보이게. 소포는 갈색 상자 위에 요금 조건을 붙인 송장처럼.
- **소리:** 우표 붙임 "찰싹", 발송 소인 "쾅", 동전 "짤랑", 반송 가로채기 "삐빅". 발송할 때 소인 찍는 손맛을 가장 크게 연출한다.
