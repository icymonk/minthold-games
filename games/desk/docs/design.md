# 땡땡이 (Away From Desk) 게임 기획서 v1

> **한 줄 소개:** 17:18, 사원이 슬그머니 자리에서 일어난다. 18:00 퇴근까지 42분 동안 몰래 자리를 비운 시각을 숨겨라. 팀장은 "17:31에 어디 있었어?"를 물어 땡땡이 기록을 전부 밝혀내야 한다.
> **키워드:** 2D · 카드 · 1대1 숨바꼭질 추리 · 혼자서 AI와 대결(역할 선택) · 10분 한 판 · 사무실 코미디

모티브: 보드게임 「Fugitive」(Tim Fowers, Fowers Games 2017)의 구조(0~42 숫자 카드를 오름차순으로 뒷면 배치 · 앞 카드보다 최대 3 큰 수 · 카드를 버려 거리를 늘리는 전력 질주 · 상대가 숫자를 불러 맞히기 · 마지막 추격). 소재, 카드 이름·사건 카드·문구, 그림은 모두 새로 만든다.

---

## 1. 개요

### 1.1 콘셉트

금요일 오후, 사원 **정 사원**은 일이 손에 안 잡힌다. 17:18에 "잠깐 화장실 좀…" 하고 일어난 뒤로 탕비실, 옥상, 1층 편의점을 전전하며 18:00 정시 퇴근만 기다린다.

**한 팀장**은 뭔가 이상하다. 출입카드 기록과 메신저 상태를 뒤져 "17:31에 너 탕비실 있었지?" 하고 하나씩 짚는다. 땡땡이 기록을 **전부** 짚어 내면 정 사원은 회의실로 불려 간다. 18:00까지 버티면 정 사원은 퇴근 도장을 찍고 사라진다.

### 1.2 기본 사양

| 항목 | 방향 |
|---|---|
| 장르 | 1대1 카드 추리(숨는 쪽 vs 찾는 쪽), 싱글(AI 상대) |
| 역할 | 판마다 **팀장**(추리, 기본 추천) 또는 **사원**(숨기) 선택 |
| 플랫폼 | 웹 미리보기 → PC / Steam |
| 그래픽 | 2D 플랫 일러스트, 사무실 오후(창으로 기우는 햇빛 + 형광등 + 포스트잇) |
| 조작 | 마우스 클릭·드래그, 숫자판 클릭 |
| 1판 | 약 8~12분 |
| 언어 | 한국어, 영어 (처음부터 번역 테이블) |

### 1.3 핵심 재미

1. **팀장: 범위 좁히기.** 내 손의 카드, 이미 짚은 시각, 사원이 어느 구역 더미에서 카드를 뽑았는지, 기록 밑에 깔린 뛰기 카드 수로 "이 기록은 17:24~17:27 중 하나"까지 좁힌다.
2. **사원: 허세와 손패 관리.** 뛸 필요 없는데 뛰기 카드를 깔아 범위를 넓혀 보이거나, 팀장이 방금 틀린 시각에 일부러 숨는다. 대신 카드를 아끼지 않으면 18:00 전에 손이 마른다.
3. **줄다리기 속도.** 사원이 앞서 나갈수록 팀장은 뒤를 쫓기 어렵다. 팀장은 한 번에 여러 시각을 걸어 따라잡을 수 있지만, 하나라도 틀리면 아무것도 밝혀지지 않는다.
4. **마지막 추궁.** 사원이 18:00 카드를 냈을 때 팀장이 많이 뒤처져 있으면, 한 번도 틀리지 않고 남은 기록을 모두 짚는 마지막 추궁에 건다.

### 1.4 비슷한 게임과 차별점

| 게임 | 공통점 | 이 게임의 차이 |
|---|---|---|
| Fugitive (보드게임) | 구조 전체 | 사무실 땡땡이 소재, 숫자를 시각(17:18~18:00)으로 읽음, 디지털 AI 상대·자동 메모판, 사건 카드 새로 설계 |

## 2. 카드

### 2.1 기록 카드 (0~42, 43장)

카드 번호 n은 시각 **17:18 + n분**으로 읽는다. 화면에는 큰 시각(예: `17:31`)과 작은 번호(`13`)를 함께 쓴다.

| 번호 | 시각 | 카드 | 구역 더미 |
|---|---|---|---|
| 0 | 17:18 | 자리에서 일어남 (시작 기록, 앞면) | – |
| 1~3 | 17:19~17:21 | 처음 손패 | – |
| 4~14 | 17:22~17:32 | 층 안 (탕비실·화장실·복사실·자료실) | 1번 더미 「층 안」 |
| 15~28 | 17:33~17:46 | 건물 안 (옥상·휴게실·지하 주차장·로비) | 2번 더미 「건물 안」 |
| 29~41 | 17:47~17:59 | 건물 밖 (편의점·카페·은행·택배 보관함) | 3번 더미 「건물 밖」 |
| 42 | 18:00 | 퇴근 도장 | 처음 손패 |

- 기록 카드마다 **뛰기 값**(발자국 1개 또는 2개)이 있다. 초기값: 번호가 3의 배수인 카드(3, 6, 9 … 39)는 발자국 2개, 나머지는 1개. 0과 42는 뛰기로 쓸 수 없다. (2단계 시뮬레이터로 조정)
- 장소 그림은 같은 구역 안에서 돌아가며 붙는다. 장소는 분위기용이고 규칙에는 영향이 없다.

### 2.2 사건 카드 (선택 규칙, 3단계)

원작의 사건 카드는 쓰지 않고 사무실 사건을 새로 만든다. 기본 판에는 넣지 않고, 제목 화면 [사건 카드]에서 켠다. 켜면 사원 처음 손패를 준 뒤 10종 중 6장을 구역 더미마다 무작위 2장씩 섞어 넣는다. 뽑은 사람이 바로 처리하고, 뽑기 횟수는 줄지 않는다(1장 더 뽑음). 사건과 단서는 양쪽 모두 본다.

"다음 차례"는 그 쪽의 다음 차례, "이번 차례"는 그 쪽 차례에 뽑았을 때만 이번이고 아니면 다음 차례다.

| 사건 | 돕는 쪽 | 효과 |
|---|---|---|
| 출입카드 기록 | 팀장 | 가장 이른 뒷면 기록이 어느 구역인지 공개 |
| CCTV 돌려보기 | 팀장 | 가장 최근 뒷면 기록이 홀수인지 짝수인지 공개 |
| 옆자리 제보 | 팀장 | 사원 손패(42 제외)에서 무작위 1장 공개. 그때까지의 기록에는 없는 번호가 된다 |
| 긴급 회의 소집 | 팀장 | 사원은 다음 차례에 기록을 낼 수 없다(뽑고 쉬기만) |
| 상태 메시지 "회의 중" | 사원 | 팀장은 다음 차례에 시각 1개만 짚을 수 있다 |
| 팀장 통화 중 | 사원 | 팀장은 다음 차례에 카드를 뽑지 않는다 |
| 엘리베이터 바로 옴 | 사원 | 사원은 이번 차례 뛰기 +2를 공짜로 얻는다(기록에 남아 팀장도 안다) |
| 핑계 준비 | 사원 | 사원은 아무 더미에서 2장 더 뽑는다 |
| 회식 공지 | 둘 다 | 둘 다 아무 더미에서 1장씩 더 뽑는다 |
| 복도에서 마주침 | 둘 다 | 팀장의 이번 짚기가 틀려도, 그 시각보다 이른 기록이 몇 장인지 알게 된다 |

시뮬레이터(꼼꼼 vs 꼼꼼 1500판): 사건 카드 켜면 사원 승률 48%(끄면 50%), 평균 사원 차례 10.5.

## 3. 한 판의 흐름

```
준비: 0(17:18)을 가운데 줄에 앞면으로 → 기록 카드를 구역 더미 3개로 나눠 섞음
      사원 처음 손패: 1, 2, 3, 42 + 「층 안」 4장 + 「건물 안」 3장
      팀장 처음 손패: 없음
차례: 사원부터 번갈아
  사원 첫 차례 : 기록 1~2장을 낸다
  팀장 첫 차례 : 2장 뽑기(더미 자유) → 짚기
  사원 차례   : 1장 뽑기(더미 자유) → 기록 1장 내기 또는 쉬기
  팀장 차례   : 1장 뽑기(더미 자유) → 짚기
끝: 사원이 42(18:00)를 내면(마지막 추궁을 넘기면) 사원 승리
    팀장이 뒷면 기록을 모두 밝히면 팀장 승리
```

### 3.1 사원: 기록 내기

- 새 기록은 가운데 줄 맨 오른쪽에 **뒷면**으로 놓는다.
- 번호는 바로 앞 기록보다 커야 하고, **최대 3까지** 클 수 있다(앞이 4면 5·6·7).
- **뛰기:** 손패를 기록 밑에 뒷면으로 깔면 그 카드들의 뛰기 값 합만큼 범위가 늘어난다(앞이 4이고 발자국 3개를 깔면 10까지). 깐 **장수는 팀장에게 보인다**(값은 안 보임). 필요 없는데 더 깔아도 된다.
- 쉬기: 기록을 안 내고 카드만 모은다.

### 3.2 팀장: 짚기

- **하나 짚기:** 1~41 중 한 시각을 부른다. 뒷면 기록 중에 있으면 그 기록과 밑에 깔린 뛰기 카드가 모두 앞면이 된다. 뛰기 카드 번호는 짚을 필요가 없다.
- **여러 개 짚기:** 시각 여러 개를 한 번에 부른다. 모두 맞으면 전부 앞면, 하나라도 틀리면 아무것도 안 뒤집힌다(어느 게 틀렸는지도 모른다).
- 팀장 손에 든 카드 번호는 사원 기록일 수 없다. 이것이 팀장의 주된 단서다.

### 3.3 마지막 추궁

사원이 42를 냈을 때 **앞면 기록 중 가장 큰 번호가 31(17:49) 이하**면, 팀장은 마지막 추궁을 할 수 있다. 남은 뒷면 기록을 하나씩 짚고, 하나라도 틀리면 그 자리에서 사원 승리, 모두 맞히면 팀장 승리.

## 4. 디지털로 바꾸며 더하는 것

- **자동 메모판:** 0~42 숫자판. 내 손의 카드·앞면 카드·틀린 단일 짚기는 자동으로 지워지고, 팀장은 직접 표시(의심·제외)도 할 수 있다. 여러 개 짚기가 틀린 경우는 "이 중 하나 이상 틀림" 묶음으로 남는다.
- **범위 표시(팀장, 쉬움 난이도만):** 뒷면 기록마다 가능한 번호 범위를 옅게 보여 준다. 보통 이상에서는 끈다.
- **행동 기록 줄:** "정 사원: 「건물 안」에서 1장 뽑음", "정 사원: 기록 1장(뛰기 2장)". 원작에서 눈으로 보던 정보(어느 더미에서 뽑았나, 뛰기 장수)를 모두 남긴다.
- **기록 보기(사원):** 내가 낸 기록과 밑의 뛰기 카드를 늘 볼 수 있다.

## 5. AI 상대

- 각 AI는 **자기가 아는 것만** 안다. 판정과 화면도 같은 정보 모델을 거친다(치트 없음).
- **AI 팀장:** 남은 뒷면 기록 각각에 대해 "가능한 번호" 분포를 계산한다. 조건은 오름차순, 앞 기록과의 거리 ≤ 3 + 뛰기 합(깐 장수 k이면 최대 2k), 내가 쥔 카드·앞면 카드·틀린 단일 짚기 제외, 사원이 뽑은 더미 기록. 확률이 가장 높은 번호를 짚고, 확실한 번호가 2개 이상이면 묶어서 짚는다. 앞서 달아나는 사원을 막으려고 높은 더미를 일부러 뽑아 "길막"도 한다.
- **AI 사원:** 18:00까지 남은 거리와 손패를 비교해 낼지 쉴지 정한다. 팀장이 방금 틀린 번호, 팀장이 쥐었을 리 없는 번호를 선호하고, 가끔 필요 없는 뛰기 카드를 깔아 허세를 부린다.
- **성격 3종:** 꼼꼼(계산대로), 눈치(최근 정보에 과하게 반응), 막무가내(무작위성 큼). 난이도는 무작위성과 계산 깊이로 조절.
- AI 행동은 0.6~1.2초 간격으로 보여 주고 기록 줄에 남긴다.

│                                                      │

│ └──────────────┘                                     │
│ ┌──┐┌──┐┌──┐┌──┐┌──┐  ← 내 손패           [규칙] [짚기]│

- 사원일 때: 카드를 가운데 줄로 끌면 낼 수 있는 번호만 빛나고, 뛰기 칸에 손패를 끌어 범위를 늘린다.

- 규칙 요약은 늘 열 수 있다. 첫 판은 역할별 짧은 안내가 차례에 맞춰 뜬다(건너뛰기 가능).

## 7. 판 밖의 진행 (3단계)

- **한 주:** 월~금 5판. 팀장이면 "잡은 땡땡이", 사원이면 "정시 퇴근" 횟수로 주간 평가. 금요일 판은 사건 카드가 켜진다.
- 기록: 역할별 승률, 평균 판 길이, 마지막 추궁 성공률.
- 시드 입력으로 같은 판 다시 하기.
