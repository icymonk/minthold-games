# 개발 단계 계획

기획: `docs/design.md`

각 항목은 PR 하나 단위다. 위에서부터 차례로 진행한다.

## 0단계 — 기반
- [ ] 0-1 Godot 4.7 프로젝트, 화면 전환 뼈대, gdUnit4, CI(`hive.yml` → 공용 `godot.yml`), 웹 미리보기 `minthold-hive`

## 1단계 — 규칙 엔진 (화면 없이 테스트로 검증)
- [ ] 1-1 카드 데이터(꽃·벌 무리·혜택·날씨·계절 목표), 계절별 꽃 더미, 시드 고정 섞기
- [ ] 1-2 꽃 조건 판정기: 손 + 꿀 ±1 + 좋아하는 꽃 + 혜택으로 조건을 맞추는 조합 찾기, 필요한 최소 꿀 계산, 테스트
- [ ] 1-3 턴·라운드·계절 진행: 행동 4종, 꿀 생산·창고 한도·판매, 양봉장 6칸, 야생 벌떼, 종료·점수 계산

## 2단계 — 한 판 화면 (재미 검증 1: "조합 맞추기가 재밌나")
- [ ] 2-1 꽃밭·양봉장 화면: 꽃밭, 떠도는 벌 무리, 벌통 자리 2칸, 양봉장, 손, 꿀 창고, 계절·라운드 표시
- [ ] 2-2 꽃 끌어다 놓기, 들일 수 있는 벌 무리 표시, 꿀 쓰기, 들이기·꿀 생산 연출
- [ ] 2-3 AI 1명(초보 양봉가 하늘)과 한 판, 결과 화면(점수 내역)

## 3단계 — 엔진과 AI (재미 검증 2: "언제 점수로 갈아탈지 고민되나")
- [ ] 3-1 1회 혜택 5종, 영구 혜택 9종
- [ ] 3-2 날씨 5종, 계절 목표 6종
- [ ] 3-3 AI 3명(성향별), AI 턴 배속·건너뛰기
- [ ] 3-4 밸런스 봇: AI끼리 시드 200판, 첫 벌통 순서별 승률·생산형/점수형 비율·꿀 판매 비중 출력

## 4단계 — 다듬기
- [ ] 4-1 첫 판 안내(행동 3번, 꿀 쓰는 법, 엔진 개념), 늘 보이는 도움말
- [ ] 4-2 저장(판 중간 이어 하기), 설정, 번역(ko/en), 효과음, 계절 배경 전환

## 5단계 — 확장·출시 (MVP 이후)
- 양봉 5년, 오늘의 꽃밭, 벌 도감, 핫시트, 일러스트 교체, Steam 상점 페이지
