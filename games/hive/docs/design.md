# 꿀 따는 계절 (Honey Season) 게임 기획서 v1

> **한 줄 소개:** 봄부터 가을까지 세 계절 동안 꽃을 모아 벌 무리를 내 양봉장에 들이고, 들인 벌통이 매 계절 꿀을 만들어 주는 힘으로 다른 양봉가보다 더 많은 꿀 점수를 내는 카드 조합 + 엔진 빌딩 게임.
> **키워드:** 2D · 카드 조합 · 한 턴에 행동 3번 · 엔진 빌딩(벌통이 꿀을 만든다) · 계절 3개 · AI 양봉가와 대결 · 일상 소재

---

## 1. 개요

### 1.1 콘셉트

산골 마을 양봉가들이 같은 꽃밭을 나눠 쓴다. 꽃밭에 핀 꽃을 따 모아 조합을 맞추면, 떠돌던 벌 무리가 내 벌통에 자리를 잡는다.

자리 잡은 벌통은 버려지지 않고 **양봉장에 남아 매 라운드 꿀을 만든다.** 꿀은 꽃 값을 ±1 바꾸는 데 쓰거나, 계절이 끝날 때 팔아 점수로 바꾼다. 먼저 벌통을 들여 엔진을 키울지, 점수 큰 벌 무리를 노릴지가 핵심 고민이다.

실력이 드러나는 곳은 **엔진을 언제 그만 키우고 점수로 돌릴지 정하는 타이밍**이다.

이 게임의 규칙 뼈대는 보드게임 「몰타르의 포탈(Die Portale von Molthar, AMIGO 2015)」을 참고했다(1.4). 형제 게임 [`postage`](../../postage/docs/design.md)와 뼈대가 같지만, 이 게임은 **벌통이 계속 꿀을 만드는 엔진**과 **계절 3개로 정해진 길이**가 중심이다. 카드 이름·문구·조건 목록·그림은 모두 새로 만든다.

### 1.2 기본 사양

| 항목 | 방향 |
|---|---|
| 장르 | 턴제 카드 조합 + 엔진 빌딩, 싱글(AI 양봉가 1~3명과 대결) |
| 플랫폼 | PC / Steam (Steam Deck 대응 목표), 개발 중에는 웹 미리보기. 나중에 모바일 |
| 그래픽 | 2D 수채화풍 일러스트, 꽃밭과 양봉장을 위에서 본 한 화면 |
| 조작 | 마우스 클릭·드래그(꽃을 벌 무리에 끌어다 놓음), 컨트롤러 대응 |
| 1판 시간 | 약 20~25분 (계절 3개, AI 3명 기준) |
| 언어 | 한국어, 영어 (처음부터 번역 테이블로 관리) |

### 1.3 핵심 재미

1. **조합 맞추기:** 손에 든 꽃 5장과 꿀로 어느 벌 무리를 들일 수 있는지 계산한다.
2. **엔진이 굴러가는 맛:** 봄에 들인 벌통이 여름·가을 내내 꿀을 만든다. 일찍 들일수록 오래 번다.
3. **언제 멈출까:** 꿀을 많이 만드는 벌통은 점수가 낮고, 점수 큰 벌 무리는 꿀을 거의 안 만든다. 가을이 다가올수록 점수 쪽으로 갈아탄다.
4. **계절마다 바뀌는 꽃밭:** 봄은 낮은 값 꽃, 가을은 높은 값 꽃이 많이 핀다. 같은 조합도 계절마다 어려움이 다르다.

### 1.4 비슷한 게임과 차별점

| 게임 | 공통점 | 이 게임의 차이 |
|---|---|---|
| 몰타르의 포탈 (보드게임) | 규칙 뼈대(행동 3번, 숫자 카드 조합으로 카드 발동, 슬롯 2칸) | 발동한 카드가 **매 라운드 자원(꿀)을 만든다**. 12점 선착이 아니라 **계절 3개로 길이가 정해짐**. 계절별 꽃 분포, 날씨 |
| 형제 게임 `postage` | 같은 뼈대 | `postage`는 12점 선착 경쟁, 이 게임은 정해진 길이 안에서 엔진 키우기 |
| Splendor | 엔진을 키워 점수로 돌리는 구조 | 자원 토큰이 아니라 숫자 조합 퍼즐, 엔진이 직접 자원을 만든다 |
| Apiary in Flow, Beekeeper Simulator 등 | 양봉 소재 | 증분·경영 시뮬이 아니라 카드 조합 대결 |

Steam에서 "honey season", "hive keeper", "beekeeper"로 검색했을 때 같은 이름이나 양봉 카드 조합 게임은 찾지 못했다. 「Hivekeeper(s)」라는 이름은 있어서 피했다(2026-11 Steam 상점 검색 기준).

## 2. 한 판의 흐름

```
[준비] 꽃밭 4장 + 떠도는 벌 무리 2개 공개, 각자 벌통 자리 2칸 + 빈 양봉장
[계절] 봄 → 여름 → 가을, 계절마다 라운드 4번
  [라운드 시작] 양봉장 벌통마다 꿀 생산 → 꿀 창고 한도 넘으면 버림
  [턴] 행동 3번 → 손 5장 넘으면 버림 → 다음 사람
  [계절 끝] 날씨 카드 교체, 꽃 더미에 다음 계절 꽃 섞기, 계절 목표 점수
[끝] 가을 마지막 라운드 후 → 남은 꿀 판매 → 최고 점수 승리
```

- **점수** = 양봉장 벌통 점수 + 계절 목표 점수 + 꿀 판매 점수. 동점이면 남은 꿀이 많은 사람이 이긴다.
- 판 길이가 정해져 있어서(3계절 × 4라운드 = 12턴) 엔진 게임이 끝없이 늘어지지 않는다.

## 3. 카드

### 3.1 꽃 카드 (계절별 더미)

- 값 1~8. 값마다 꽃 이름이 있다: 1 민들레, 2 유채, 3 클로버, 4 아카시아, 5 밤꽃, 6 해바라기, 7 메밀, 8 들국화.
- 계절마다 더미 구성이 다르다(MVP 기준, 합계 60장):

| 계절 | 많이 피는 값 | 구성 |
|---|---|---|
| 봄 | 1~4 | 1~4 각 4장, 5~8 각 1장 (20장) |
| 여름 | 3~6 | 3~6 각 4장, 1·2·7·8 각 1장 (20장) |
| 가을 | 5~8 | 5~8 각 4장, 1~4 각 1장 (20장) |

- 계절이 바뀌면 남은 꽃 더미와 버림 더미에 다음 계절 꽃 20장을 섞는다. 지난 계절 꽃이 조금씩 남는다.
- 손 한도 5장. 턴이 끝날 때만 검사한다.

### 3.2 벌 무리 카드 (MVP 40장)

| 항목 | 설명 |
|---|---|
| 꽃 조건 | 들이려면 내야 하는 꽃 조합 (3.3) |
| 점수 | 0~5점 |
| 꿀 생산 | 라운드마다 0~2개. **점수가 높을수록 생산이 적다** (예: 점수 1·꿀 2, 점수 4·꿀 0) |
| 혜택 | 없음 / 1회(빨강) / 영구(파랑) (5장) |
| 좋아하는 꽃 | 일부 벌 무리에 인쇄된 꽃(값 또는 "아무 꽃"). 양봉장에 있으면 이후 다른 벌 무리를 들일 때마다 한 번 꽃 1장으로 쳐 준다 |

### 3.3 꽃 조건 (MVP 12종)

| 이름 | 조건 | 난이도 |
|---|---|---|
| 한 가지 꽃 | 같은 값 2장 | 쉬움 |
| 꽃다발 | 서로 다른 값 3장 | 쉬움 |
| 봄 들판 | 1~3 값 3장 | 보통 |
| 가을 들판 | 6~8 값 3장 | 보통 |
| 꿀 무게 | 합계가 정확히 N (N = 10~16, 장수 자유) | 보통 |
| 단일 꿀 | 같은 값 3장 | 보통 |
| 짝수 꽃밭 | 짝수 값 3장 | 보통 |
| 홀수 꽃밭 | 홀수 값 3장 | 보통 |
| 두 꽃밭 | 두 쌍 | 어려움 |
| 꽃 피는 순서 | 연속 값 3장 | 어려움 |
| 사계절 꽃길 | 연속 값 5장 | 아주 어려움 |
| 여왕의 취향 | 인쇄된 값 2~3장 그대로 | 어려움 |

## 4. 턴

### 4.1 행동 (아래 4개 중 3번, 같은 행동 반복 가능, 순서 자유)

1. **꽃 따기:** 꽃밭 4장 중 1장 또는 더미 맨 위 1장을 손에 넣는다. 꽃밭에서 가져가면 바로 더미에서 채운다.
2. **꽃밭 갈아엎기:** 꽃밭 4장을 모두 버리고 새로 4장을 깐다.
3. **벌 무리 부르기:** 떠도는 벌 무리 2개 중 하나 또는 더미 맨 위 1장을 내 벌통 자리에 올린다. 자리는 2칸. 꽉 찼으면 하나를 날려 보내고(버림) 올린다.
4. **벌통 들이기:** 벌통 자리에 있는 벌 무리 하나의 꽃 조건에 맞는 꽃을 내고, 그 벌 무리를 양봉장으로 옮긴다. 점수와 혜택을 받고, 다음 라운드부터 꿀을 만든다.

### 4.2 꿀

- **꽃 값 바꾸기:** 꿀 1개로 꽃 1장의 값을 +1 또는 −1 한다(1~8 안에서). 꽃 1장에 꿀 1개까지. (`postage`의 동전은 +1만 되는데, 이 게임은 꿀이 흔한 대신 둘 다 된다.)
- **꿀 창고 한도:** 6개. 라운드 시작 생산 후 넘치는 꿀은 버린다. 쌓아 두기만 하는 것을 막는다.
- **꿀 판매:** 계절이 끝날 때와 게임 끝에 꿀 3개를 1점으로 바꿀 수 있다.

### 4.3 양봉장

- 양봉장은 6칸. 꽉 찼으면 새 벌통을 들일 때 기존 벌통 하나를 내보낸다(그 벌통 점수는 잃는다). 생산형 벌통을 점수형으로 바꾸는 판단이 여기서 나온다.

### 4.4 야생 벌떼

- 벌 무리 중 4장은 "야생" 표시가 있다. 내 벌통 자리에 올리면 **양옆 양봉가가 자기 턴에 먼저 들여 갈 수 있다.** 들이면 점수 3, 꿀 생산 0.

### 4.5 날씨 (계절마다 1장, 원작에 없는 장치)

| 날씨 | 효과 |
|---|---|
| 맑음 | 효과 없음 |
| 장마 | 이번 계절 "꽃밭 갈아엎기" 불가 |
| 가뭄 | 이번 계절 꽃밭이 3장만 열림 |
| 말벌 습격 | 계절 시작에 모두 꿀 절반(내림)을 잃음. "방충망" 혜택이 있으면 막음 |
| 풍년 | 이번 계절 꿀 생산 +1(벌통마다가 아니라 양봉가마다) |

### 4.6 계절 목표 (원작에 없는 장치)

- 계절마다 목표 카드 1장을 공개한다(예: "양봉장 벌통 3개 이상", "이번 계절 꿀 5개 이상 판매", "짝수 조건 벌통 2개"). 계절이 끝날 때 달성한 양봉가는 2점.

## 5. 혜택

**1회(빨강):** 들인 즉시 한 번 쓰고 끝.

| 이름 | 효과 |
|---|---|
| 분봉 | 행동 3번을 바로 더 한다 |
| 이웃 품앗이 | 다음 양봉가는 다음 턴에 행동 +1 |
| 꽃가루 나르기 | 상대 한 명의 손을 보고 꽃 1장을 가져온다 |
| 다시 핀 꽃 | 방금 낸 꽃 1장을 손으로 돌려받는다 |
| 영역 다툼 | 상대 벌통 자리의 벌 무리 하나를 날려 보낸다 |

**영구(파랑):** 양봉장에 있는 동안 계속.

| 이름 | 효과 | 쓰는 때 |
|---|---|---|
| 민들레 사랑 | 민들레(1)를 들국화(8)로 쓸 수 있다 | 들일 때 |
| 클로버 밭 | 클로버(3)를 아무 값으로 쓸 수 있다 | 들일 때 |
| 원심 분리기 | 내 턴 아무 때 꿀 2개를 1점으로 바꾼다(턴당 한 번) | 내 턴 |
| 큰 꿀 창고 | 꿀 창고 한도 +3 | 항상 |
| 큰 손 | 손 한도 +1 | 항상 |
| 여왕벌 | 매 턴 행동 +1 | 항상 |
| 방충망 | 말벌 습격을 막는다 | 계절 시작 |
| 춤추는 정찰벌 | 첫 행동 전에 꽃 더미 맨 위 2장을 보고 순서를 정한다 | 턴 시작 |
| 벌통 옮기기 | 첫 행동 전에 내 벌통 자리 벌 무리 1개와 떠도는 벌 무리 1개를 맞바꾼다 | 턴 시작 |

## 6. AI 양봉가 (MVP 3명)

| 이름 | 성향 |
|---|---|
| 초보 양봉가 하늘 | 쉬움. 당장 들일 수 있는 벌 무리만 노린다 |
| 꿀 장수 덕배 | 보통. 생산형 벌통으로 엔진을 키우고 꿀을 판다 |
| 양봉 명인 순자 | 어려움. 여름부터 점수형으로 갈아타고, 야생 벌떼와 계절 목표를 노린다 |

- AI는 규칙 엔진의 "가능한 행동 목록"을 받아 점수를 매겨 고른다. 같은 시드면 같은 수를 둔다.
- AI의 손은 보이지 않는다. 장수와 꿀 개수만 보인다.

## 7. 반복 플레이

- **양봉 1년차~5년차 (정식 출시):** 해마다 한 판. 이기면 다음 해 시작 벌통 하나를 고른다. 해가 갈수록 날씨가 거칠어진다.
- **오늘의 꽃밭:** 날짜 시드로 모두 같은 카드 순서를 받아 점수를 겨룬다(정식 출시).
- **벌 도감:** 처음 들인 벌 무리를 도감에 모은다. 새 벌 무리와 혜택이 덱에 섞인다.

## 8. MVP 범위

### 8.1 목표

**AI 1~3명과 세 계절 한 판을 끝까지 할 수 있는 프로토타입.** "엔진이 굴러가는 맛이 있나", "언제 점수로 갈아탈지 고민되나"를 먼저 검증한다.

### 8.2 콘텐츠 수량

| 항목 | MVP | 정식 출시 목표 |
|---|---:|---:|
| 꽃 | 60 (계절별 20) | 60 |
| 벌 무리 | 40 | 70 |
| 꽃 조건 | 12 | 20 |
| 혜택 | 1회 5 + 영구 9 | 1회 10 + 영구 16 |
| 날씨 | 5 | 10 |
| 계절 목표 | 6 | 15 |
| AI 양봉가 | 3 | 6 |
| 모드 | 한 판 | 한 판 + 양봉 5년 + 오늘의 꽃밭 |

### 8.3 반드시 구현할 것

1. 계절별 꽃 더미, 꽃밭, 벌 무리 더미, 버림 더미, 섞기
2. 행동 4종, 행동 3번, 손 한도, 라운드·계절 진행
3. 꽃 조건 판정(꿀 ±1, 좋아하는 꽃, 혜택 포함)과 "지금 들일 수 있는 벌 무리" 표시
4. 꿀 생산·창고 한도·판매, 양봉장 6칸
5. 혜택 14종, 야생 벌떼, 날씨 5종, 계절 목표 6종
6. AI 3명, 시드 고정, 결과 화면(점수 내역)

### 8.4 MVP에서 뺄 것

양봉 5년, 오늘의 꽃밭, 벌 도감, 온라인 대전, 모바일 빌드, 일러스트 본작업.

## 9. 위험 요소

| 위험 | 문제 | 대응 |
|---|---|---|
| 눈덩이 | 봄에 벌통을 먼저 들인 사람이 끝까지 앞선다 | 꿀 창고 한도, 생산형은 점수가 낮음, 양봉장 6칸, 말벌 습격. 밸런스 봇으로 "첫 벌통 순서별 승률" 확인 |

## 12. 아트 가이드 (프로토타입 기준)

- **방향:** 산비탈 꽃밭과 나무 벌통이 놓인 양봉장을 위에서 본 화면. 아래쪽에 내 손과 벌통 자리 2칸·양봉장, 위쪽에 꽃밭·떠도는 벌 무리·AI 양봉장. 계절마다 배경색이 바뀐다.
- **색상표:** 꿀 `#F2A900`, 밀랍 `#F6E7B0`, 나무 벌통 `#B07A47`, 봄 연두 `#B8E08C`, 여름 초록 `#4E9F3D`, 가을 주황 `#D9822B`, 벌 검정 `#2B2B2B`.
