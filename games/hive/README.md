# 꿀 따는 계절 (`hive`)

**꿀 따는 계절 (Honey Season)** — 세 계절 동안 꽃을 조합해 벌 무리를 들이고, 들인 벌통이 만드는 꿀로 엔진을 키워 AI 양봉가보다 높은 점수를 내는 카드 조합 게임 (Godot 4, Steam).

- 기획서: [docs/design.md](docs/design.md)
- 개발 단계: [docs/plan.md](docs/plan.md)
