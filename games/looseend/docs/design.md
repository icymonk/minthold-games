# 끝이 어디야? (Loose End) 게임 기획서 v1

> **한 줄 소개:** 투명 테이프의 끝을 빛과 손끝 감각으로 찾아내고, 찢지 않고 뜯어내는 짧은 촉감 퍼즐 게임.
> **키워드:** 2D · 일상 소재 · 촉감 퍼즐 · 짧은 단계 · 빛 반사 · "아 이거 진짜 짜증나는데"

---

## 1. 개요

### 1.1 콘셉트

이삿날이다. 상자는 산더미인데 테이프 끝이 안 보인다. 롤을 돌려 가며 빛에 비춰 보고, 손톱으로 표면을 긁어 "틱" 걸리는 곳을 찾는다. 찾았으면 살살 들어 올려 쭉 뜯는다. 너무 세게 당기면 비스듬히 찢어져서 가는 띠만 나오고, 끝은 다시 숨어 버린다.

누구나 겪어 본 짜증을 **조작 자체가 퍼즐인 게임**으로 만든다. 설명 없이 화면 한 장으로 바로 알아듣는 것이 목표다.

### 1.2 기본 사양

| 항목 | 방향 |
|---|---|
| 장르 | 싱글 촉감 퍼즐, 단계형 + 점수 도전 |
| 플랫폼 | PC / Steam (Steam Deck 대응 목표), 웹 미리보기. 나중에 모바일(터치가 잘 맞음) |
| 그래픽 | 2D, 손과 롤을 크게 그린 클로즈업 한 화면 |
| 조작 | 마우스(돌리기·긁기·당기기), 조명은 휠 또는 두 번째 드래그. 컨트롤러는 스틱 + 진동 |
| 1단계 시간 | 30초~2분 |
| 언어 | 한국어, 영어. 글자가 거의 없게 만든다 |

### 1.3 핵심 재미

1. **찾는 맛:** 눈으로는 안 보이는 끝을 빛 반사(반짝임), 손끝 걸림(소리·진동), 테이프 결로 추리한다.
2. **조심하는 맛:** 들기와 당기기는 힘 조절이다. 서두르면 찢어지고, 찢어지면 처음부터 다시 찾아야 한다.
3. **공감 웃음:** 끝이 접혀 붙어 버리는 순간, 랩이 뭉쳐 손에 감기는 순간 같은 "아 진짜" 장면이 연출의 중심이다.
4. **다음을 위한 배려:** 다 쓰고 나서 끝을 살짝 접어 두면(탭) 다음에 바로 찾는다. 대신 시간이 든다. 미래의 나를 위한 선택.

### 1.4 비슷한 게임과 차별점

| 게임 | 공통점 | 이 게임의 차이 |
|---|---|---|
| Peel Me | 벗겨 내는 촉감 | 벽지를 계속 뜯는 증분 게임. 이 게임은 **숨은 끝 찾기**가 중심 |
| Needle In A Haystack 류 | 일상 속 "찾기" | 화면에서 그림 찾기가 아니라 빛·촉감 단서로 찾는 조작 퍼즐 |
| Unpacking | 이사·일상 소재 | 정리가 아니라 테이프 하나에 집중하는 짧은 퍼즐 |
| 숨은그림찾기 | 찾기 | 눈만이 아니라 손끝 감각(소리·진동)이 단서 |

Steam에서 "tape end", "find the end", "loose end"로 검색했을 때 같은 소재 게임은 찾지 못했다(2026-11 Steam 상점 검색 기준).

## 2. 한 판의 흐름

```
[1장 이삿날] 박스테이프 단계 5개
[2장 미술 시간] 마스킹 테이프 단계 5개
[3장 야식] 주방 랩 단계 5개
[4장 전기 공사] 절연·덕트 테이프 단계 5개
→ 장마다 별 3개 평가, 별로 다음 장과 도구 해금
```

- 한 단계의 목표는 "상자 N개를 테이프로 붙여라" 같은 짧은 일이다. 테이프 한 줄을 붙일 때마다 끝을 찾고, 뜯고, 붙이고, 자른다.
- **별 기준:** 시간, 찢어진 횟수, 마지막에 끝을 접어 두었는지.
- 장 끝에 **점수 도전** 단계: 롤 하나를 60초 동안 최대한 많이 뜯기.

## 3. 테이프 롤

### 3.1 화면

- 화면 가운데에 롤을 크게 그린다. 보이는 건 롤의 바깥 표면이다.
- **드래그로 롤을 돌린다.** 표면이 돌아가며 다른 부분이 보인다.
- **조명:** 화면 위쪽 전등을 좌우로 옮기면(휠 또는 오른쪽 드래그) 빛이 비치는 각도가 바뀐다. 끝 선과 빛 각도가 맞으면 끝 선이 잠깐 반짝인다.

### 3.2 끝의 상태

| 상태 | 설명 | 찾기 난이도 |
|---|---|---|
| 접어 둔 탭 | 끝이 살짝 접혀 튀어나옴 | 바로 보임 |
| 깨끗한 끝 | 곧게 잘린 끝. 반짝임과 걸림이 잘 느껴짐 | 보통 |
| 비스듬한 끝 | 찢어져서 사선. 끝 선이 길고 걸림이 약함 | 어려움 |
| 눌어붙은 끝 | 접혀서 표면에 납작하게 붙음 | 매우 어려움 |
| 갈라진 끝 | 가는 띠가 따로 떨어져 끝이 2개처럼 보임 | 가짜 끝에 속기 쉬움 |

### 3.3 단서 세 가지

1. **반짝임(눈):** 조명 각도가 끝 선과 맞을 때만 잠깐 빛난다.
2. **걸림(손):** 손톱으로 표면을 긁을 때 테이프가 감긴 반대 방향으로 끝을 지나가면 "틱" 소리와 함께 커서가 살짝 걸린다. 감긴 방향으로 긁으면 아무것도 안 느껴진다. 방향을 아는 것도 실력이다.
3. **결(눈):** 먼지나 지문이 끝 선에서 끊겨 보인다. 단계가 올라가면 먼지가 줄어 단서가 사라진다.

## 4. 들기와 뜯기

### 4.1 들기

- 끝에 손톱을 걸고 누른 채 좌우로 살살 흔든다. 모서리가 조금씩 들린다(진행 막대).
- 너무 크게 흔들면 손톱이 미끄러지고, 들리던 끝이 다시 눌어붙는다.
- 모서리에서 시작하면 쉽고, 가운데에서 시작하면 사선으로 찢어지기 쉽다.

### 4.2 뜯기

- 들린 끝을 잡고 화면 밖으로 당긴다.
- **당기는 각도와 속도**로 찢어질 위험이 정해진다. 화면에 "팽팽함"을 테이프 색 변화로 보여 준다(투명 → 하얗게 늘어남).
- 너무 빠르거나 비스듬하면 찢어진다. 찢어지면 가는 띠만 남고 끝은 갈라진 끝 상태가 된다.
- 붙일 길이만큼 뜯었으면 상자 위에 붙이고 자른다(톱니 날에 대고 아래로 한 번).

### 4.3 끝 접어 두기

- 자른 뒤 2초 동안 끝을 접어 둘 수 있다. 다음 줄은 바로 시작한다.
- 대신 단계 시간이 흐른다. 남은 상자가 적으면 안 접는 게 이득이다.

## 5. 테이프 종류 (MVP 4종 + α)

| 종류 | 특징 |
|---|---|
| 투명 박스테이프 | 기본. 반짝임이 잘 보이고 걸림이 뚜렷함 |
| 마스킹 테이프 | 종이라 잘 보이지만 아주 잘 찢어짐. 힘 조절 연습 |
| 주방 랩 | 끝이 아예 안 보이고 정전기로 손에 감김. 롤을 거꾸로 돌리면 들뜸 |
| 덕트 테이프 | 끝은 잘 보이지만 결 방향으로만 곧게 찢어짐. 손으로 자르기 |
| (확장) 양면테이프 | 비닐 막과 테이프 두 겹의 끝을 따로 찾아야 함 |
| (확장) 절연 테이프 | 늘어나서 당기면 얇아지다 끊김 |

## 6. 방해 요소 (단계별)

| 방해 | 내용 |
|---|---|
| 부르는 소리 | "잠깐 이것 좀!" 손을 떼면 들던 끝이 다시 붙음 |
| 고양이 | 뜯은 테이프에 달려들어 엉킴. 빨리 붙여야 함 |
| 장갑 | 목장갑 단계: 걸림 감각이 둔해짐 |
| 정전 | 조명이 없어 손끝 걸림만으로 찾기 |
| 새 롤 | 비닐 포장을 먼저 뜯어야 함(포장 끝 찾기) |

## 7. 도구 (해금)

| 도구 | 효과 | 대가 |
|---|---|---|
| 손톱 기르기 | 걸림이 더 잘 느껴짐 | 들기 때 미끄러지기 쉬움 |
| 커터 칼끝 | 눌어붙은 끝도 들 수 있음 | 표면을 긁으면 가짜 끝이 생김 |
| 테이프 커터(디스펜서) | 끝이 항상 날 위에 있음 | 박스테이프 단계에서만, 무거워 붙이는 속도 느림 |
| 손전등 | 조명 각도를 롤 가까이에서 자유롭게 | 한 손을 씀: 들기 진행 느림 |

## 8. MVP 범위

### 8.1 목표

**1장(박스테이프) 5단계 + 점수 도전 1개를 끝까지 할 수 있는 프로토타입.** 재미의 핵심인 "찾기 → 들기 → 뜯기"를 먼저 검증한다.

### 8.2 콘텐츠 수량

| 항목 | MVP | 정식 출시 목표 |
|---|---:|---:|
| 테이프 종류 | 1 (박스테이프) | 6 |
| 단계 | 5 + 점수 도전 1 | 30 + 점수 도전 6 |
| 방해 요소 | 1 (부르는 소리) | 5 |
| 도구 | 0 | 4 |

### 8.3 반드시 구현할 것

1. 롤 돌리기, 조명 각도, 반짝임
2. 손톱 긁기, 방향에 따른 걸림 피드백(소리 + 커서 걸림)
3. 들기(흔들기 진행), 미끄러짐
4. 뜯기(각도·속도, 팽팽함 표시), 찢어짐 → 끝 상태 변화
5. 붙이고 자르기, 끝 접어 두기
6. 단계 목표, 별 3개 평가, 기록

### 8.4 MVP에서 뺄 것

2~4장, 도구, 모바일 빌드, 리더보드, 업적, 일러스트 본작업.

## 9. 위험 요소

| 위험 | 문제 | 대응 |
|---|---|---|
| 진짜로 짜증남 | 현실의 짜증을 그대로 옮기면 재미가 아니라 고통 | 단서는 항상 공정하게(반짝임·걸림은 확실히), 실패 연출은 웃기게, 단계는 짧게 |
| 금방 질림 | 같은 동작 반복 | 테이프 종류마다 규칙을 다르게, 방해 요소, 점수 도전 |
| 감각 전달 | 화면만으로 "걸림"이 느껴질까 | 소리(틱) + 커서 0.1초 멈춤 + 컨트롤러 진동 + 화면 미세 흔들림. 프로토타입에서 가장 먼저 검증 |
| 분량이 적음 | 한 소재로 몇 시간을 채우기 어려움 | 가격을 낮게(소품 게임), 1~2시간 완주 + 점수 도전으로 반복 |

## 10. 제목

**확정: 「끝이 어디야?」 / Loose End**

- "Loose end"는 실·테이프의 풀린 끝이라는 뜻과 "마무리 안 된 일"이라는 뜻이 함께 있다. Steam에서 같은 이름은 찾지 못했다(2026-11 기준).
- 검토했던 다른 후보: Tape End, Sticky End(어감이 어둡다), Unstuck.
- 코드명은 `looseend`(`games/looseend/`, Firebase 사이트 `minthold-looseend`).

## 12. 아트 가이드 (프로토타입 기준)

- **방향:** 방 안 책상 위 클로즈업. 따뜻한 형광등 빛, 골판지 상자, 손은 단순한 만화 손(장갑 쓴 것처럼 단색).
- **색상표:** 책상 나무 `#B98A5E`, 골판지 `#C8955C`, 벽 크림 `#F3EBDD`, 테이프 하이라이트 `#FFFFFF`(투명 부분은 흰색 반사로만 표현), 손 `#F2C9A0`, 강조 노랑 `#FFD447`, 실패 빨강 `#E0523F`.
- **반짝임:** 끝 선을 따라 흰 빛이 0.3초 지나가는 연출. 투명 테이프는 테두리와 반사로만 그린다.
- **소리:** 걸림 "틱", 들기 "찌익", 찢어짐 "빡", 접혀 붙음 "철썩". 소리가 단서이므로 처음부터 넣는다.
