# 장작이 꺼지기 전에 (Keep the Fire) 게임 기획서 v1

> **한 줄 소개:** 눈보라에 갇힌 산장. 낮에는 생존자들을 숲으로 보내 장작을 모으고, 밤에는 난로로 다가오는 추위와 늑대를 카드로 막는다. 불이 셀수록 카드가 강해지지만 장작은 빨리 탄다.
> **키워드:** 생존 덱빌딩 · 불 = 힘 = 목숨 · 낮 탐색 / 밤 방어 · 생존자 갈등 · 한 겨울 더

공통 기준(로그라이트 구조, 콘솔식 큰 화면, 단계별 안내)은 [`docs/game-guide.md`](../../../docs/game-guide.md)를 따른다. 이 문서는 이 게임에서 정하는 것만 적는다.

---

## 1. 개요

### 1.1 콘셉트

산길 버스가 눈사태에 막혔다. 승객 몇 명이 겨우 찾아낸 건 낡은 산장과 무쇠 난로 하나. 무전기는 "12일 뒤 구조대 출발"이라는 말만 남기고 끊겼다. 숲에는 장작과 늑대가 있고, 산장 안에는 서로 못 믿는 사람들이 있다.

### 1.2 기본 사양

| 항목 | 방향 |
|---|---|
| 장르 | 1인 생존 덱빌딩 로그라이트. 한 판(겨울 한 번) 35~45분 |
| 전체 플레이 | 첫 구조까지 4~6시간, 해금 전부 15시간 이상, 그 뒤 혹한 단계·끝없는 겨울 |
| 플랫폼 | PC / Steam(Steam Deck), 웹 미리보기. 나중에 모바일 |
| 그래픽 | 2D. 가운데 난로, 둘레에 문·창문·굴뚝 세 줄. 불빛 세기에 따라 화면 밝기가 바뀐다. Kenney CC0 팩 + 도형 그림 |
| 조작 | 마우스·터치·패드: 카드 고르기 → 줄(문·창문·굴뚝) 고르기 |
| 언어 | 한국어, 영어 |

### 1.3 핵심 재미

1. **불 줄타기:** 난로 불꽃 단계(1~5)가 이번 턴 기력이자 카드 위력 배수다. 장작을 넣으면 강해지지만 장작이 다 떨어지면 끝이다. "지금 태울까, 아낄까"가 매 턴 고민이다.
2. **낮의 욕심:** 숲 깊이 갈수록 좋은 것이 나오지만, 해가 지기 전에 못 돌아오면 생존자가 동상을 입는다.
3. **사람이 곧 덱:** 생존자 한 명이 덱에 카드 3장을 넣는다. 사람을 구하면 덱이 커지고, 다치면 카드가 「부상」으로 바뀌고, 잃으면 카드가 사라진다.
4. **위력 폭발:** 피해 = 카드 열 × 불꽃 단계 × 연쇄. 불이 5단계일 때 연쇄를 이으면 늑대 무리가 한 번에 쓸려 나간다.

### 1.4 비슷한 게임과 차별점

| 게임 | 공통점 | 이 게임의 차이 |
|---|---|---|
| Slay the Spire | 덱, 유물, 보스, 갈림길 | 적을 다 쓰러뜨리는 게 아니라 **새벽까지 버티기**. 기력·체력·배수가 **난로 불 하나**로 묶여 있다 |
| Frostpunk | 추위, 난로, 생존자 | 도시 경영이 아니라 한 밤의 카드 방어. 사람이 덱의 일부다 |
| Don't Starve | 숲 탐색, 밤의 위험 | 실시간 조작 없이 차례제. 낮은 갈림길 지도 고르기 |

Steam 검색(2026-11)에서 "Until the Fire Dies", "Last Ember"는 이미 있다. 영어 제목은 같은 이름이 없는 "Keep the Fire"로 한다.

## 2. 한 판의 흐름

```
런 = 12밤, 3막
  1막 첫눈(1~4밤) → 2막 한겨울(5~8밤) → 3막 마지막 추위(9~12밤)
하루 = 낮(숲 탐색) → 저녁(산장) → 밤(방어)
막 마지막 밤 = 보스 밤
```

- 12번째 밤을 넘기면 구조대가 오고 완주다. 그 뒤 **끝없는 겨울**로 계속할 수 있다.
- 난로 불이 꺼지거나 생존자가 모두 쓰러지면 런이 끝난다.

### 2.1 낮: 숲 탐색 (갈림길 지도)

- 산장에서 숲 지도가 펼쳐진다. 칸은 산장에서 1~4걸음 떨어져 있다. 낮 시간은 **해 6칸**이다.
- 생존자마다 칸 하나를 고른다. 가는 데 걸음 수만큼, 돌아오는 데 같은 만큼 해를 쓴다. 해를 넘기면 그 생존자는 「동상」(카드 하나가 부상 카드가 됨).
- 칸 종류:

| 칸 | 얻는 것 | 위험 |
|---|---|---|
| 벌목터 | 장작 | 낮음 |
| 덫 사냥터 | 식량 | 낮음 |
| 버려진 오두막 | 산장 물건(유물) 1개 | 중간: 동물 흔적 |
| 얼어붙은 호수 | 물고기(식량 많이), 드물게 귀한 물건 | 얼음이 깨질 수 있음 |
| 낯선 발자국 | 새 생존자, 또는 이벤트 | 결과를 모른다 |
| 무너진 버스 | 카드 3장 중 1장 | 중간 |

- 생존자 고유 능력이 탐색을 바꾼다. 예: 「산악회 아저씨」는 걸음 −1, 「사냥꾼」은 사냥터에서 식량 ×2.

### 2.2 저녁: 산장

- **식량 나누기:** 생존자마다 식량 1. 못 먹으면 「배고픔」(그 생존자 카드 기력 +1).
- **카드 정리:** 숲에서 얻은 카드 넣기, 장작 2개로 카드 하나 강화, 카드 하나 태우기(덱에서 빼기).
- **사기 이벤트:** 사기가 낮으면 갈등이 터진다. "누가 장작을 몰래 쓰고 있다", "한 명이 혼자 내려가겠다고 한다". 고르는 답에 따라 생존자·장작·카드가 바뀐다.
- **밤 예고:** 오늘 밤 어느 줄로 무엇이 올지 일부가 보인다.

### 2.3 밤: 방어 (6턴 버티면 새벽)

- 가운데 난로, 둘레에 **문·창문·굴뚝** 세 줄. 위협은 각 줄 끝(거리 3)에서 나타나 턴마다 한 칸씩 다가온다.
- 턴 시작: 카드 5장을 뽑고, **기력 = 불꽃 단계**. 불꽃 단계는 턴이 끝날 때마다 1씩 떨어진다.
- 카드를 내서 위협을 밀어내거나 쓰러뜨린다. 거리 0에 닿은 위협은 효과를 낸다.
  - 추위: 불꽃 −1 (불을 직접 깎는다)
  - 늑대: 생존자 하나에게 상처
  - 눈 더미: 줄을 막아 그 줄에 카드를 못 낸다
- **장작 넣기:** 언제든 장작 1개 = 불꽃 +1(최대 5). 장작은 런 전체 자원이라 밤마다 아껴야 한다.
- 6턴 뒤 새벽이 오면 남은 위협은 물러가고, 남은 불꽃 단계만큼 장작을 돌려받는다.

### 2.4 위력 계산 (공통 가이드의 기본 점수 × 배수)

```
피해 = 카드 열 × 불꽃 단계 × 연쇄
```

- **연쇄:** 같은 턴에 같은 줄로 카드를 연달아 내면 1, 2, 3…으로 오른다. 다른 줄로 옮기면 1로 돌아간다.
- 예: 불꽃 5에서 「횃불 휘두르기」(열 3)를 연쇄 3으로 내면 45. 불꽃 1이면 같은 카드가 3이다.
- 큰 숫자가 나오면 불길이 화면 밖까지 치솟고 늑대가 날아간다.

### 2.5 목표 (초기값, 4-3에서 조정)

| 밤 | 1 | 2 | 3 | 4(보스) | 6 | 8(보스) | 10 | 12(보스) |
|---|---|---|---|---|---|---|---|---|
| 위협 체력 합 | 20 | 35 | 55 | 120 | 160 | 400 | 500 | 1200 |

## 3. 생존자와 카드

### 3.1 생존자 (시작 3명 + 숲에서 합류, 최대 5명)

생존자 한 명 = 고유 카드 3장 + 낮 능력 하나 + 체력 3. 상처 3이면 쓰러지고 그 사람의 카드가 덱에서 빠진다.

| 생존자 | 낮 능력 | 카드 성격 |
|---|---|---|
| 버스 기사 | 돌아오는 해 −1 | 방어(줄 막기) |
| 간호사 | 저녁에 상처 1 치료 | 회복, 부상 카드 되돌리기 |
| 산악회 아저씨 | 걸음 −1 | 밀어내기 |
| 사냥꾼 | 사냥터 식량 ×2 | 높은 열, 연쇄 |
| 대학원생 | 오두막에서 물건 2개 중 고르기 | 카드 뽑기, 기력 |
| 아이 | 사기 +1 | 약하지만 다른 사람 카드 강화 |
| 전직 소방관 | 장작 넣기 효율 ×2 | 불꽃 조작 |
| 수상한 사람 | 비밀이 있다(아래) | 강하지만 장작을 먹는다 |

- 시작 덱: 공용 카드 6장(「막기」 3, 「밀치기」 3) + 시작 생존자 3명의 카드 9장 = 15장.
- 보상 카드는 3장 중 1장. 공용 카드와 생존자 카드가 섞여 나오고, 생존자 카드는 그 사람이 살아 있어야 나온다.

### 3.2 카드 종류

| 종류 | 예 |
|---|---|
| 공격(열) | 「횃불 휘두르기」 열 3, 「끓는 물」 열 2·줄 전체 |
| 밀어내기 | 「문 걸어 잠그기」 문 줄 위협을 거리 +2 |
| 불꽃 | 「풀무질」 이번 턴만 불꽃 +2, 「마른 솔방울」 장작 없이 불꽃 +1 |
| 생존 | 「붕대」 상처 1 치료, 「따뜻한 국」 배고픔 제거 |
| 저주 | 「부상」(쓸 수 없음), 「공포」(뽑으면 기력 −1) |

### 3.3 산장 물건 (유물)

런이 끝날 때까지 계속 효과가 난다. 출시 60종. 예:
- 「할머니 담요」: 새벽마다 불꽃 1 덜 떨어진다.
- 「녹슨 도끼」: 벌목터 장작 +1.
- 「라디오」: 밤 예고가 한 줄 더 보인다.
- 「성냥 한 갑」: 밤마다 처음 넣는 장작은 공짜.
- 「보온병」: 연쇄가 다른 줄로 옮겨도 1로 안 돌아간다(한 번).

### 3.4 수상한 사람 (원작 모티브)

「봉투」의 몰래 빼 가는 사람을 이 게임에 들였다. 낯선 발자국에서 합류하는 생존자 중 일부는 **도둑**일 수 있다. 도둑은 밤마다 장작을 하나씩 몰래 쓴다. 장부의 숫자가 이상하다는 힌트가 쌓이면 저녁에 "내보내기"를 고를 수 있다. 맞히면 숨긴 장작을 되찾고, 틀리면 사기가 크게 떨어진다.

## 4. 보스 밤

막의 마지막 밤. 규칙 하나를 깨는 큰 위협이 나온다. 출시 12종(막마다 4종 중 하나).

| 보스 | 규칙 |
|---|---|
| 굶주린 우두머리 | 늑대가 쓰러지면 무리가 하나 더 온다 |
| 대한파 | 턴마다 불꽃이 2씩 떨어진다 |
| 눈사태 | 3턴째에 한 줄이 끝까지 막힌다 |
| 흰 곰 | 한 줄에서 천천히 다가오고 체력이 아주 높다 |
| 굴뚝새 떼 | 굴뚝 줄 위협이 닿으면 불꽃 −2 |
| 긴 밤 | 새벽까지 8턴 |

## 5. 오래 하기 (전체 플레이 5시간 이상)

| 요소 | 내용 | 대략 시간 |
|---|---|---|
| 첫 구조 | 12밤 완주. 보통 4~7번 시도 | 4~6시간 |
| 시작 조합 | 생존자 8명 중 시작 3명을 고른다. 처음엔 3명 고정, 해금하며 늘어난다 | 조합마다 1~2시간 |
| 산장 일지 | 카드·물건·보스·이벤트 도감. "불꽃 1로 보스 밤 넘기기" 같은 과제로 새 카드·물건이 풀린다 | 15시간 이상 |
| 혹한 단계 1~10 | 완주할 때마다 하나씩. 위협 강화, 해 −1, 장작 시작량 감소 등이 누적된다 | 25시간 이상 |
| 끝없는 겨울 | 13번째 밤부터 계속. 버틴 밤 수가 기록 | 끝없음 |
| 오늘의 눈보라 | 날마다 같은 seed, 기록 비교 | 매일 |

- 능력치 영구 강화는 없다. 해금은 **고를 거리**만 늘린다(공통 가이드 1장).
- 판이 끝나면 산장 일지 한 장: 가장 큰 한 방, 끝까지 남은 사람, 무엇 때문에 졌는지.

## 6. 화면

공통 가이드 2장의 크기 기준(1080p, 지시 문구 64px, 점수 120px, 버튼 160px)을 지킨다.

```
┌─────────────────────────────────────────────────────────────┐
│ 3막 · 10번째 밤 · 새벽까지 ●●●○○○       장작 7   식량 4      │
│                                                             │
│             [굴뚝 줄]  ▲ 굴뚝새 2                            │
│   [문 줄] 늑대 →→  ( 난로 · 불꽃 4 )  ←← 추위 [창문 줄]        │
│                                                             │
│  [기사][간호사][사냥꾼]  상처 ●○○ / ●●○ / ○○○   [장작 넣기]   │
│  [카드][카드][카드][카드][카드]   기력 4/4      [ 턴 끝 ]      │
└─────────────────────────────────────────────────────────────┘
```

- 불꽃 단계에 따라 화면 전체 밝기와 색이 바뀐다. 불꽃 1이면 화면이 푸르고 어둡다.
- 카드를 들면 줄 세 개가 빛나고, 놓을 곳 위에 예상 피해가 크게 뜬다.
- 실패: 불이 꺼지는 소리, 화면이 하얗게 얼어붙으며 서리가 퍼진다.

### 6.1 처음 할 때 안내 (`Coach`)

1. 숲 지도에서 생존자를 벌목터로 보내기(구멍: 벌목터) → 보내면 다음
2. 밤: 카드를 문 줄에 내기(구멍: 손패, 문 줄) → 내면 다음
3. 불꽃 단계와 기력 보기(구멍: 난로) → 누르면 다음
4. 「장작 넣기」 누르기(구멍: 장작 버튼) → 넣으면 다음
5. 첫 저녁: 카드 하나 고르기 → 고르면 다음

## 7. 구조

[`games/rooster/docs/architecture.md`](../../rooster/docs/architecture.md)와 같은 규칙(Godot 4.7.x, GDScript, gdUnit4, 웹 미리보기)을 따른다.

```
Run (순수 로직, RefCounted, seed 결정론)
  ├─ Day: ForestMap.roll(rng) → 칸들, Expedition.send(survivor, node) → 결과
  ├─ Camp: 식량, 카드 정리, 사기 이벤트
  ├─ Night: Lane × 3, Threat, Hearth(불꽃·장작)
  │    Night.play(card, lane) / feed() / end_turn() → NightLog(발동 순서 기록)
  ├─ Hook: 물건·생존자·보스가 같은 발동 지점에 붙는다
  │    on_turn_start / on_play / on_damage / on_threat_reach / on_dawn ...
  └─ Reward.roll(rng) → 카드 3장, 물건
화면(Control 씬)은 NightLog를 받아 차례대로 연출만 한다.
```

- `tools/sim.gd`: 탐욕 봇이 같은 seed로 런을 돌려 밤별 생존율, 장작 잔량, 카드·물건별 승률을 출력한다.

## 8. MVP 범위

### 8.1 목표
웹에서 12밤 런 하나를 끝까지 할 수 있고, 불을 태울지 아낄지가 매 턴 고민되는지 확인한다(3단계 끝).

### 8.2 콘텐츠 수량 (MVP → 출시)
- 생존자 5 → 8, 카드 60 → 120, 산장 물건 30 → 60, 위협 12 → 24, 보스 6 → 12, 숲 이벤트 20 → 50

### 8.3 MVP에서 뺄 것
- 수상한 사람(도둑) 시스템은 3단계 끝에 재미 검증 뒤 넣는다
- 온라인 순위표, 모바일 빌드

## 9. 위험 요소

| 위험 | 대응 |
|---|---|
| 불 아끼기만 정답이 됨 | 남은 불꽃이 새벽 장작으로 돌아오게 해서 태우는 것도 손해가 아니게 한다. 봇으로 "항상 아끼기" 전략의 승률을 따로 잰다 |
| 낮 탐색이 지루한 반복 | 낮은 한 화면, 30초 안에 끝낸다. 칸 종류와 이벤트를 막마다 바꾼다 |
| 생존자를 잃으면 회복 못 함 | 낯선 발자국에서 새 사람을 구할 기회를 막마다 보장한다 |
| Slay the Spire와 비슷함 | 버티기 승리, 불 하나로 묶인 자원, 사람이 곧 덱이라는 세 가지를 앞에 세운다 |
