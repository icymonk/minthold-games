# 게임 공통 가이드

`games/` 아래 모든 게임이 따르는 기준이다. 새 게임 기획서(`docs/design.md`)는 이 문서를 전제로 쓰고, 다른 점만 적는다. 기존 게임은 다음 작업 때 이 기준에 맞춘다.

## 1. 장르: 로그라이트

모든 게임은 로그라이트 구조로 만든다. 소재가 일상 동작이어도 "한 판 더"를 부르는 뼈대는 같다.

| 요소 | 기준 |
|---|---|
| 한 판(런) | 15~30분. 실패하면 처음부터 다시 |
| 판마다 다름 | 무대·손님·물건·이벤트를 seed로 무작위 생성. 같은 seed면 같은 판 |
| 고르기 | 무대 사이에 보상 **3장 중 1장** 고르기. 카드·도구가 규칙을 비틀어 빌드가 생긴다 |
| 점수 폭발 | 기본 점수 × 배수. 마지막에 곱해지는 순간을 크게 터뜨린다 |
| 실패 | 와장창·화면 흔들림·소리로 크게. 무엇 때문에 졌는지 한 장면으로 보여 준다 |
| 영구 성장 | 판이 끝나면 새 카드·무대·꾸미기가 조금씩 풀린다. 능력치 영구 강화는 최소로 |
| 판정 | 규칙은 직접 만든 결정론 코드(테스트 가능), 물리 엔진은 연출만 |

## 2. 화면: 콘솔 게임처럼 크게

TV 앞 소파(약 2.5m)에서도 읽히는 크기로 만든다. 기준 해상도는 1920×1080이다.

### 2.1 크기

| 대상 | 최소 크기 (1080p 기준) |
|---|---|
| 지시 문구 (화면에 하나) | 64px, 굵게 |
| 본문·설명 | 40px |
| 점수·배수 숫자 | 120px 이상, 터질 때 더 커짐 |
| 고르는 버튼·카드 | 높이 160px 이상, 사이 간격 32px |
| 화면 가장자리 여백 | 사방 5% (글자·버튼은 이 안쪽) |

### 2.2 글자보다 그림

- **버튼은 그림이 먼저다.** 큰 아이콘 + 짧은 한 단어. 글자만 있는 버튼은 만들지 않는다.
  - 예: 「다시 당기기」 → 되감기 화살표 + "다시", 「다음 상차림」 → 오른쪽 화살표 붙은 식탁 그림 + "다음", 「제목으로」 → 집 아이콘.
- **상태는 그림·색·움직임으로 보여 준다.** 남은 기회는 하트·접시 아이콘 줄, 진행도는 무대 아이콘 길, 위험은 빨간 떨림. 숫자와 글로 쓴 설명은 보조다.
- **화면에 글은 한 줄만.** 지금 할 일 하나(12자 안팎). 규칙 설명 문단은 쓰지 않는다. 설명이 필요하면 아래 3장의 안내로 직접 해 보게 한다.
- **고르기는 큰 카드.** 카드 한 장이 화면 폭의 약 1/4. 그림이 카드의 절반 이상이고, 효과는 아이콘 + 숫자(예: 와인잔 그림 ×2)로 쓴다. 긴 설명은 카드를 고르고 있을 때만 아래에 크게 띄운다.
- 그림은 CC0 팩(Kenney 등)을 기본으로 쓴다. 직접 그린 도형은 임시로만 쓴다.

### 2.3 조작

- 핵심 동작 하나는 설명 없이 따라 할 수 있어야 한다. 잡을 곳은 빛나고 흔들리며, 손가락 그림이 동작을 반복해서 보여 준다.
- 메뉴·카드 고르기는 마우스, 터치, 키보드·패드 어느 것으로도 된다. 지금 고른 것은 두꺼운 테두리와 확대로 분명하게 표시한다.
- 누를 수 있는 것은 눌렀을 때 바로 반응한다(눌림 모양, 소리, 0.1초 안).

## 3. 처음 할 때 안내 (driver.js식)

웹의 driver.js처럼 화면 위에 단계별 안내를 띄운다. 처음 판에만 자동으로 나오고, 언제든 건너뛸 수 있다.

### 3.1 모양

```
┌──────────────────────────────────────────┐
│ ▓▓▓▓▓▓▓▓ 화면 전체를 어둡게 ▓▓▓▓▓▓▓▓▓▓▓▓ │
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  ┌─────────┐ ▓▓▓▓▓▓▓ │
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  │ 밝은 구멍 │ ◀ 지금 볼 것 하나
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  └─────────┘ ▓▓▓▓▓▓▓ │
│ ▓▓▓▓▓▓  ┌───────────────────────┐ ▓▓▓▓▓▓ │
│ ▓▓▓▓▓▓  │ [그림]  여기를 잡아요!   │ ▓▓▓▓▓▓ │ ◀ 말풍선: 그림 + 한 줄
│ ▓▓▓▓▓▓  │      ● ● ○ ○   [건너뛰기]│ ▓▓▓▓▓▓ │ ◀ 단계 점 + 건너뛰기
│ ▓▓▓▓▓▓  └───────────────────────┘ ▓▓▓▓▓▓ │
└──────────────────────────────────────────┘
```

- 어두운 막에 **밝은 구멍(스포트라이트)** 하나를 뚫어 지금 볼 것만 보이게 한다. 구멍은 대상으로 부드럽게 옮겨 가고, 테두리가 숨 쉬듯 빛난다.
- 말풍선은 구멍 옆에 붙는다. 큰 그림이나 움직이는 손가락 + 한 줄(40px 이상) + 단계 점(● ● ○ ○) + 「건너뛰기」.
- 단계는 4~6개. 한 단계에 하나만 알려 준다.

### 3.2 진행

- **직접 해 봐야 다음으로 넘어간다.** "식탁보를 잡아요" 단계는 실제로 잡아야 넘어간다. 보기만 하는 단계(게이지, 점수)는 화면 아무 곳이나 누르면 넘어간다.
- 구멍 안의 대상만 누를 수 있고, 나머지 화면은 막는다. 「건너뛰기」는 늘 누를 수 있다.
- 처음 보는 화면(첫 가게, 첫 카드)에 처음 들어갈 때 그 화면의 안내가 한 번 더 나온다.
- 본 안내는 저장해서 다시 띄우지 않는다. 설정에서 「안내 다시 보기」로 처음부터 볼 수 있다.

### 3.3 구현

- 게임마다 `scripts/ui/coach.gd`(`Coach` 노드, 맨 위 `CanvasLayer`)를 둔다. 셰이더로 막에 둥근 사각형 구멍을 낸다.
- 단계는 데이터로 적는다.

```gdscript
const STEPS := [
	{"id": &"grab", "target": "Stage/ClothEdge", "text": "COACH_GRAB", "icon": "hand", "wait": &"grabbed"},
	{"id": &"gauge", "target": "Gauge", "text": "COACH_GAUGE", "wait": &"tap"},
]
```

- `target`은 구멍을 낼 노드, `wait`는 넘어갈 조건(그 화면이 내는 시그널 이름, 또는 `tap`)이다.
- 문구는 `i18n/strings.csv`의 `COACH_*` 키로 둔다.
